# Fehlerbilder und Gegenbelege

| Fehlannahme | Gegenbeleg im 2. OG | Beispiel |
| --- | --- | --- |
| Jede dicke Linie ist Mauer | Beschriftete Brüstung oder Konstruktionsdarstellung | W08 |
| Jeder Bogen ist eine Tür | Rahmen und Parapethöhe eines Fensters | F01/F02 |
| Kleiner Fensterbogen ist normale Gehöffnung | Wartungsflügel mit Öffnungsbegrenzer | F03 |
| Glas ist durchgehbar, weil man hindurchsieht | Durchgehendes festes Fassadenfeld | D04 |
| Kleine Wanddicke bedeutet freie Passage | Feste Kabinentrennwand | W05 |
| Weiß im Plan ist automatisch Boden | Umwehrter Bereich mit ungeklärtem Niveau | W08/G02 |
| Grüner Raum ist Durchgangsroute | Ein Zugang, feste übrige Grenzen | G03 |
| Viele parallele Linien sind Treppe | Garderobenraster und entsprechender Raumstempel | S05 |
| Treppenbruch ist eine querende Mauer | Lage im Lauf und fortlaufende Stufenbelege | S02 |
| Aufzug ist freie Fläche oder Treppe | Schacht, Kabine und FWA-Text | W06/S02 |
| Wartungssteg ist normaler Gang | Explizite Wartungsbezeichnung | G04 |
| Kleine Konturlücke erzeugt eine Tür | Im Original keine belegte Öffnung | Regel R10 |

Diese Gegenbeispiele dienen der qualitativen Kontrolle. Sie sind keine automatisch gemessenen Fehlerzahlen der bestehenden Engine.
