### KNX Systemgeräte: Netzwerk, Topologien, IP Secure — S.216-217
KNX-Netzwerk bietet Schnittstellen zu Ethernet (LAN) und DALI; via KNXnet/IP Anbindung an Gebäudemanagementsysteme. **KNX IP Secure** überträgt KNX-Telegramme sicher über Ethernet, nutzt vorhandene Netzwerk-Infrastruktur über größere Entfernungen.
**Topologie-Nomenklatur:** S = Bereich (1 = Westflügel, 2 = Ostflügel), SC = Bereichskoppler, LC/LK = Linienkopplung, L = Linie, F = Etage (F1-F5); L0 = Bereichslinie 0.
- Klassisch: alle Linien-/Bereichskoppler als KNX-Koppler, Busleitungslängen meist auf ein Gebäude begrenzt.
- Modern: Bereichskoppler durch IP Router Secure ersetzt (nicht mehr auf Busleitungslänge begrenzt; auch LWL/WLAN).
- Innovativ: alle Linienkoppler durch IP Router Secure ersetzt, keine Bereichskoppler nötig, jedes Stockwerk per Ethernet; Austausch von Gruppenadressentelegrammen trotz Trennung in Einzelprojekte möglich.

### Technischer Anhang — Richtlinien, CE, Prüfzeichen — S.230-232
S.230 Schalter-Übersichtsbild: Serien-, Wechsel-, Kreuzschalter.
**EU-Richtlinien (S.232):**
1. **2014/30/EU EMV-Richtlinie** — elektromagnetische Verträglichkeit; gilt für Betriebsmittel (Geräte/ortsfeste Anlagen), die Störungen verursachen/durch Störungen beeinträchtigt werden; auch vom Endnutzer einbaubare Bauteile/Baugruppen.
2. **2014/35/EG Niederspannungsrichtlinie** — elektrische Betriebsmittel in Grenzen: **Wechselstrom 50-1000 V, Gleichstrom 75-1500 V**. SCHUKO-Steckdosen (Haushaltssteckvorrichtungen) ausdrücklich von der Kennzeichnung ausgeschlossen.
