### Konventionen / Bedienoberfläche (Einleitung)
- Befehlsschrift: Befehle (CIRCLE, LINE, ZOOM, MIRROR) in Command-Font; Systemprompts in eigenem Stil; **Nutzereingaben fett**.
- Enter/Return-Taste (Symbol ⏎) signalisiert Ende von: Befehlseingabe, Koordinateneingabe, Wert, Text. Ab Kap. 1 wird ⏎ nur noch gezeigt, wenn der Nutzer ⏎ drücken soll statt anderer Eingabe.
- Funktionstasten: **F6** = Koordinaten-Readout toggeln (absolut → inkrementell → aus → zurück); **F7** = GRID ein/aus; **F8** = ORTHO ein/aus; **F9** = SNAP ein/aus.
- Maus: Pick-Button (links bei Zwei-Tasten-Maus) = Befehl/Punkt picken; rechte Taste = oft ⏎-Funktion + Kontextmenü (abschaltbar unter Tools → Options → User Preferences). Rollball (Releases ab 2004) = ZOOM + PAN (drücken + bewegen).
- Arbeitsbereich: **AutoCAD Classic** aus der Workspaces-Toolbar wählen (Releases 2007/2008 zeigen sonst Dashboard). Paletten (Sheet Sets, Tool Palettes) mit "X" schließen.
- Bildschirmelemente: Menu Bar (oben, Pull-down), Status Bar (unten, Cursor-Koordinaten + GRID/SNAP-Modusbuttons), Zeichenfenster, Toolbars (Icons = Befehle). Command Line ("floating", verschieb-/andockbar, vertikal+horizontal größenänderbar via Splitter-Bar).
- Toolbars: per Rechtsklick auf Endlinien-Doppelstrich (Releases 2006-2008) oder View → Toolbars (2000-2005). Andocken durch Ziehen an Fensterrand; mit Strg gedrückt = ohne Andocken platzieren. Erste Toolbar bei leerem Screen: `Command:-toolbar` → `Standard`. Docked vs. Floating Toolbar.
- Dateispeicherung-Empfehlung: alle 30 Min auf C:/D: speichern; nach >3 h zusätzlich auf externes Medium (Flash); vor Abmelden Datei sich selbst per E-Mail schicken; immer 3 Kopien.

### Datei-Handling (Einleitung)
- OPEN (Datei öffnen), SAVE (speichern), Save As (anderer Name/Verzeichnis/Release), RECOVER (beschädigte Datei reparieren — Ursachen: defekte Disketten, Floppy zu früh entfernt). QUIT = Exit-Befehl. Großes rotes X = AutoCAD beenden, kleines schwarzes x = aktuelle Zeichnung schließen.
- NEW: Template-Datei wählen. Endung **.dwt** = drawing template. **acad.dwt = imperial**, **acadiso.dwt = metric**. Template kann Plotter-, Layer-, Gruppen-, Block-, Linetype- und Standardinfo speichern.
- Save As → "Files of Type" → z.B. "Release 2000", um für ältere Releases lesbar zu speichern.
- Options-Dialog (früher "Preferences"): Tools → Options. Display-Tab: Bildschirmfarbe (Display → Color), Rechtsklick-Voreinstellungen, Scroll Bars ein/aus, Crosshair Size, Display Resolution, Arc/Circle Smoothness, Segments in Polyline Curve, Rendered Object Smoothness, Contour Lines per Surface. Farbzuordnungen für Crosshairs, Autotrack Vector, Autosnap Marker, Command Line, Drafting Tooltip etc. (Red/Yellow/Green/Cyan/Blue/Magenta/White).

## Kapitel 1 — Introductory Geometry and Setting Up

### Metrisch vs. Imperial bestimmen / starten
- Schneller Test: Cursor nach rechts in den Zeichenbereich bewegen — Koordinaten-Readout **unter 100 = imperial**, **über 500 = metrisch**.
- Sofort in den gewünschten Einheiten starten. Falsche Einheiten → neue Datei mit acad.dwt (imperial) bzw. acadiso.dwt (metric).
- `Command:STARTUP` → `Enter new value for startup <0>:1` aktiviert beim NEW den Dialog mit reiner Imperial/Metric-Auswahl.
- Empfehlung: alles im Maßstab **1:1 / full scale** zeichnen, später beim Plotten skalieren.

### UNITS-Befehl
- UNITS setzt NUR den Readout (Anzeige), nicht das Modell. Zugriff: Format-Pull-down → Units, oder Command Line.
- Einheitentypen:
  - **Decimal** (für metrisch UND imperial nutzbar): 1 Einheit = 1 Millimeter (im metrischen Sinn). Precision = Anzahl Nachkommastellen.
  - **Engineering** und **Architectural**: 1 Zeichnungseinheit = 1 Zoll (inch). Precision separat einstellbar.
  - **Fractional** und **Scientific**: Readout in jeweiligen Einheiten.
- "Insertion scale" muss zur gewählten Einheit passen (z.B. UNITS in inches aber Insertion scale in mm → spätere Probleme).

### Koordinatensystem / Ursprung
- Kartesische Koordinaten um Ursprung **X0, Y0, Z0** (Z default 0.0000). Rechts von 0,0 = +X, links = −X; oben = +Y, unten = −Y. 0,0 defaultet auf untere linke Bildschirmecke.
- Ursprung sinnvoll auf den am leichtesten zugänglichen / am häufigsten bemaßten Punkt legen (wichtig beim späteren Mergen von Dateien).
- Architektur: Ursprung oft untere linke Ecke (Beispiel: 0,0 unten links, 35',30' oben rechts; oder −5',−5' / 50',45').
- Mechanik: Ursprung oft mittig (z.B. −2,−2 / 2,2 oder −10,−20 / 10,20).
- Ursprung verschieben mit **PAN** (Befehl P; oft Rollball drücken + ziehen).

### LIMITS, SNAP, GRID
- **LIMITS** setzt flexible Gesamtgröße/Zeichenbereich + Grid-Abdeckung; jederzeit änderbar; begrenzt das Modell NICHT.
  - `Command:LIMITS` → lower left corner, upper right corner. Beispiel Haus 40'×36': `-5',-5'` bis `45',40'`.
  - Metrik-Beispiel: `-5,-40` bis `240,180` (bzw. `-5,-5` bis `100,60` im Tutorial).
- **SNAP** setzt Cursor-Bewegungs-Increment. `Command:SNAP` → `Specify snap spacing <1.0000>:` z.B. 5 oder .25. Bei SNAP .25 → alle Eingaben auf nächstes .25-Intervall gerundet. F9 toggelt nur, Befehl ändert Größe.
- **GRID** = visuelle Hilfe, oft auf **doppelten SNAP-Wert** gesetzt. `Command:GRID` → `<0>:10`. Grid reicht über LIMITS-Bereich. F7 toggelt.
- Drafting Settings unter Tools-Pull-down erreichbar.

### Punkteingabe — drei Methoden
1. Koordinaten: absolut, relativ (inkrementell), polar.
2. Bildschirm-Pick (mit/ohne SNAP oder DYNamic).
3. Relativ zu bestehender Geometrie (OSNAP, Kap. 2).

### LINE-Befehl + Koordinatenarten
- LINE (Alias **L**). Linie = zwei Punkte; mehrere Punkte verkettbar. Command mit ⏎ beenden. Optionen: **C** = Close (schließt Linienzug vom letzten zum ersten Punkt), **U** = Undo (letzten Punkt zurücknehmen).
- **Absolute** Eingabe: X,Y relativ zum Ursprung. Bsp. `0,0` → `4,0` zeichnet Linie von absolut 0,0 nach 4,0. Quadrat-Bsp.: 0,0 → 4,0 → 4,4 → 0,4 → 0,0.
- **Relative/inkrementelle** Eingabe: **@** (Shift-2) = "vom letzten Punkt". Bsp. von 2,3 → `@4,0`. Quadrat ab 5,5: `@4,0` `@0,4` `@-4,0` `@0,-4`.
- Wahl: bekannter Endpunkt → absolut; bekannte Verschiebung → relativ.

### Polare Koordinaten
- Format **@Länge<Winkel** relativ zum letzten Punkt. Winkel werden **counterclockwise** von **+X (3-Uhr / Osten)** gemessen. 0° = Ost, 90° = Nord, 180° = West, 270° = Süd.
- Bsp. von 3,4: `@4<45`. Polygon-Bsp. ab 6,0: `@2<0` `@3<90` `@2<0` `@1<270` `@2<0` `@2<90` `@6<150` `@1<210` → `C`.

### Eingabehilfen am Statusbar
- **SNAP** (F9): Zeichnen auf voreingestellte Integer; auch winklig/isometrisch setzbar; GRID folgt SNAP. Ohne SNAP/POLAR keine Genauigkeit.
- **ORTHO** (F8): Linien nur vertikal/horizontal.
- **GRID** (F7): visuelle Distanzanzeige.
- **POLAR**: Linien vertikal/horizontal bei gegebener Distanz, zeigt inkrementelle Distanz vom letzten Punkt; Längeneingabe für 0/90/180/270°. Button "an" = eingedrückt. Bsp.: Cursor rechts → `60`, Cursor hoch → `50` ⇒ Linie 60 in +X, 50 in +Y.
- **DYNamic (DYN)**: zeigt Command Line am Cursor + dynamischen Winkel-Readout. WARNUNG: Winkel-Readouts ohne Dezimalstellen → mit DYN gezeichnete Linien oft ungenau (z.B. "33°" liegt real zwischen 33-34°). Angle-Precision in UNITS erhöhen. **Für Koordinateneingabe DYN ausschalten.** Wertebox wechselt blau→weiß bei Eingabe.

### Geometriebefehle
- **CIRCLE** (Alias C): Mittelpunkt + Radius. Optionen: **3P** (durch 3 Punkte), **2P** (durch 2 Punkte), **Ttr** (tangent-tangent-radius: tangential an zwei Objekte mit angegebenem Radius), **D** = Diameter statt Radius. Bsp. Radius 4 von 0,0.
- **ARC** (Alias A): vier Punkte (Center, Radius, Start, End). Default = 3 aufeinanderfolgende Punkte. Optionen per Anfangsbuchstabe (e=end, r=radius etc.); Zugang über Draw → Arc. Bsp. Start-End-Radius. **Bögen werden counterclockwise berechnet.**
- **FILLET** (Alias F): Bogen zwischen zwei Objekten (meist Linien); **Radius 0** = Ecken säubern/Linien zum Scheitel verbinden. Default-Radius im Bsp. 5. Radius ändern: Option **R** (gefolgt von Space) → neuer Wert (z.B. 12, 10). Anzeige "Mode = Trim, Radius = <5.0000>".

### View-Befehle (ändern nur Anzeige, nicht Koordinaten/Datenbank)
- **ZOOM** (Z): magnifiziert Ausschnitt; transparenter Befehl. Optionen: **All (A)** (an LIMITS angepasst), **Center (C)** (Magnification/Height nötig), **Dynamic (D)**, **Extents (E)** (alle Objekte einpassen), **Previous (P)**, **Realtime** (Button/Rechtsklick), **Window (W)** (Rechteck aus 2 Punkten), **Scale nX** (% der aktuellen Größe), **Scale nXP** (relativ zu Paper Space). Scale-Bsp.: .8x = 80%, .5x = 50%, 2x = doppelt. Zoom In verdoppelt, Zoom Out halbiert. In Release 2008 kann Rollball-ZOOM fehlerhaft sein → ZOOM All/Extents nutzen. "ZOOM All is your friend" — verloren gegangene Objekte zurückholen.
- **PAN** (P): verschiebt Modell ohne Magnification-Änderung; Datenbank (0,0,0 + Koordinaten) bleibt. ESC/ENTER zum Beenden; Rollball drücken+bewegen. Alternativ Windows-Scroll-Bars (Down-Pfeil bewegt Zeichnung nach oben usw.).
- **REDRAW**: aktualisiert Ansicht, löscht Blip-Marks.
- **REGEN (RE)**: rechnet Datei neu, glättet eckige/choppy Bögen+Kreise auf aktuellen Magnification-Faktor.

### Alternate Units (Nomenklatur bei Eingabe)
- **Architectural**: Default = Zoll. Bsp. `2,3` = 2",3"; `@4',0` = 4 Fuß in X; `@0,2'3` = 2 Fuß 3 Zoll in Y; `@3'4-1/2",0`. Foot-Symbol nötig: `4` = 4 Zoll, `4'` = 4 Fuß.
- **Fractional**: Bruch mit Slash `/`; gemischte Zahl mit Bindestrich `-` plus Slash. Bsp. `1-1/2,2-3/4`, `@3/4,0`.
- **Surveying** (Vermessung): Kompassrose in 90°-Quadranten (oben Nord, links West). Format z.B. `N25d0'0"E` (null Minuten/Sekunden weglassbar → `N25dE`); KEINE Leerzeichen. Bsp. `@38<S44d14'9"W`.
- **Winkelmessung**: Default 0° = Osten (3 Uhr), counterclockwise. UNITS bietet nur 4 Null-Referenz-Positionen (Nord/Ost/Süd/West); andere Orientierung über UCS. `<` vor Winkel = Messung counterclockwise von 3 Uhr (bei nicht-dezimalem Winkelmodus, z.B. Radians). Angle-Precision in UNITS einstellbar (wirkt auf POLAR/DYN-Readout).
- Wiederholter Hinweis: UNITS ändert nur den Readout — für Genauigkeit SNAP oder Koordinaten verwenden.

### Tutorials Kapitel 1 (Ablauf-Beispiele)
- **Tutorial 1a (metrisch, acadiso.dwt):** LIMITS `-5,-5` bis `100,60`, ZOOM All, SNAP 5. Außenrechteck absolut `0,0`→`75,0`→`75,50`→`0,50`→C. ZOOM Extents, ZOOM .8x. Innenrechteck mit POLAR (Cursor-Richtung + Wert) ab `5,5`: 65, 40, 65, C. Diagonalen `@20<30` ab 10,10 und `@20<150` ab 50,10. Kreise mit CIRCLE (Radius 2.7) an Snap-Punkten; Ttr-Kreis Radius 10 zwischen zwei Kreisen; FILLET Radius 10 an Innenrechteck.
- **Tutorial 1b (imperial, acad.dwt, ohne LIMITS/SNAP):** nur MODEL + POLAR an. UNITS Architectural, Precision `0'-0"`. CIRCLE `0,0` Radius `4'` (Fuß-Symbol nicht vergessen) = "Patio-Tisch". ZOOM A dann .5x. Stuhl 24"×18" mit LINE+POLAR (rechts 24, hoch 18, links 24, C). Zweiter Stuhl mit CIRCLE + ARC. Üben mit ZOOM in/out für weitere Stühle.
- **Exercise 1 — Units Practice 1:** NEW-Datei, UNITS passend setzen, Ursprung 0,0 per PAN auf Screen, erste Linie ab 0,0, ZOOM All/Rollball. Identische Geometrie in den fünf Einheitenmodi dargestellt: FRACTIONAL, DECIMAL, ARCHITECTURAL, ENGINEERING, SCIENTIFIC (z.B. wiederkehrende Maße ~3.00/2.50/1.20/0.80 dezimal; 90°/135°-Winkel; engineering/scientific Notation 1.250E+001 etc.).
