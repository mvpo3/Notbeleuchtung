### Kapitel 6 — Entity Properties: Layers, Farben, Linientypen (Seiten 124–137)

#### Grundkonzept LAYER
- `LAYER`-Befehl steuert die Zeichnung über sichtbare Entitäten (wie Folien/Transparencies). Verschiedene Farben und Linientypen können verschiedenen Layern zugeordnet werden.
- Layer können angezeigt/ausgeblendet, aktiv/inaktiv, zugänglich/unzugänglich sein. **Anzahl der Layer ist unbegrenzt.**
- Layer werden nur im **Layer Properties Manager** angelegt/geändert; der aktuelle Layer kann über die **Layer-Toolbar** gesetzt werden.

#### Layer Properties Manager — Spalten/Funktionen
- **Current**: setzt markierten Layer als aktuellen (Arbeits-)Layer.
- **Name**: Layername — **keine Leerzeichen, Schrägstriche oder Punkte erlaubt**.
- **Off/On**: macht Layer unsichtbar/sichtbar.
- **Freeze/Thaw**: friert Layer ein (unsichtbar UND nicht regeneriert) bzw. taut auf. Freeze gilt für Model-Space-Layer. Eingefrorene Layer werden bis zur Regeneration beim Auftauen nicht angezeigt.
- **Lock/Unlock**: sperrt Layer (sichtbar, aber nicht editierbar) bzw. entsperrt.
- **Color**: Farbe des Layers (eigene Farbauswahl, keine Toggle).
- **Linetype**: Linientyp des Layers.
- **Lineweight**: Linienbreite des Layers.
- **New**: neuer Layer, startet mit Default-Name (`Layer1`).
- **Delete**: löscht Layer nur, wenn er keine Objekte enthält.
- **OK**: verlässt Dialog mit Speichern; **Show Details**: mehr Statusinfo; **Cancel**: verwirft; **Help**: Hilfedateien.

#### Layer anlegen / aktivieren / umbenennen
- Neuen Layer: `New`-Button → Name eingeben (überschreibt `Layer1`). Beim erneuten Öffnen sind Layer **alphabetisch** sortiert.
- Mehrfachauswahl: Windows-Standard — **Shift** für zusammenhängenden Bereich, **Strg/Ctrl** für Einzelauswahl.
- Umbenennen: Name doppelklicken (Feld wird blau), neuen Namen eingeben.
- Aktuell setzen: Layer markieren + `Current` wählen, oder schneller über Layer-Toolbar (Dropdown). Objekte auf anderen Layer verschieben: Objekte markieren → Layer im Dropdown wählen.

#### Farbe & Linientyp
- Layerfarbe ändern: farbige Box unter Spalte **C** wählen → Select-Color-Dialog → Farbe → OK.
- **COLOR**-Befehl setzt Farbe **unabhängig vom Layer** und **übersteuert** die Layerfarbe. Empfehlung: COLOR auf **ByLayer** lassen.
  - `Command:COLOR` → alle nachfolgenden Objekte in dieser Farbe.
  - Fehlerbild: Objekte in falscher Farbe → COLOR steht nicht auf Bylayer → zurücksetzen auf Bylayer.
- **Linientypen laden**: im Layer Property Manager wie im Graphics-Bereich (Verweis S. 56). Nach externem Setzen von Farbe/Linientyp verwenden alle künftigen Objekte des Layers diese Werte. Empfehlung: Color- UND Linetype-Setting auf **ByLayer**, bis man sich sicher ist.
- **Problem-Shooting**: Verschwinden Layer plötzlich → versehentlich „New Group Filter" gewählt → im Layer Properties Manager **All Used Layers** wählen.

#### LTSCALE (Linientyp-Skalierung)
- Je nach Objektgröße erscheinen versteckte Linien evtl. nicht als gestrichelt → Linientypskala relativ zur Zeichnung ändern.
- `Command:LTSCALE` → `Enter new linetype scale factor<1.00>:12`
- Im Tutorial später auch `New scale factor<1.00>:1.5`.

#### Match Properties (`_matchprop`) und CHPROP
- **Match Properties** überträgt Linientyp, Farbe und Linientypskala (sowie Dimension Style, Hatch, Polyline, Viewport, Table, Material, Shadow display etc.) von einem Quellobjekt auf gewählte Zielobjekte.
  - Ablauf: `Select source object` → Zielobjekte wählen → Zielobjekte erhalten Eigenschaften der Quelle.
- **CHPROP** (Befehlszeile) — Eigenschaften zyklisch ändern:
  ```
  Command:CHPROP
  Select objects: (Objekt wählen)
  Enter property to change [Color/LAyer/LType/LtScale/Thickness]:c
  Enter new color <bylayer>:Red
  Enter property to change [...]:LT
  Enter new linetype <hidden>:Center
  ```
- Auf gesperrten Layern werden Objekte NICHT geändert — z. B. „40 objects on locked layers", nur Objekte des entsperrten (Objects-)Layers ändern sich.

#### Layer Filtering
- Filter begrenzt, welche Layer im Layer-Control gelistet werden. Filterkriterien:
  - Layernamen, Farben, Linientypen
  - on/off
  - frozen/thawed
  - locked/unlocked
  - plot/don't-plot-Status
  - enthält Objekte oder nicht
  - Teil einer extern referenzierten (xref) Zeichnung oder nicht
- Einsatz bei sehr großen Dateien oder Fremddateien. Filter: `New Property Filter`-Button → Filtergruppe anlegen (Beispiel: alle roten Layer filtern).

#### Layer Management — Konventionen
- **Default-Layer = `0`** (nicht umbenennbar). Bei Bemaßung entsteht zusätzlich Layer **`Defpoints`** (nicht umbenennbar, **plottet nicht**).
- Layer logisch/eindeutig benennen; LINETYPE und COLOR auf **ByLayer**.
- Viele Branchen haben **Layering-Standards** — bei Firmeneintritt Standards erfragen (firmenintern und extern).
- Einfrieren ungenutzter Layer spart bei großen Modellen viel Zeit.

### Kapitel 7 — Bemaßung / Dimensioning (Seiten 138–157)

#### Bemaßungs-Komponenten und universelle Drafting-Standards (WICHTIG, generisch)
- Bemaßung zeigt Maße, Lagen und Winkel. Befehle extrahieren die bereits in der Geometrie programmierten Größen.
- Komponenten: **dimension text** (Maßzahl), **dimension line** (Maßlinie), **extension line** (Maßhilfslinie), **arrowhead** (Pfeil), **definition/reference point** (Defpoint).
- **Universelle Maßstandards (zwingend, auch im CAD):**
  - Maßzahl-Offset von der Maßlinie: **0,625 mm bzw. 1/16 Zoll**.
  - Maßhilfslinie ist vom Bauteil um **0,625 mm bzw. 1/16 Zoll** abgesetzt.
  - Maßhilfslinie ragt **1,25 mm bzw. 1/8 Zoll** über die Maßlinie hinaus (overshoot).
- AutoCAD setzt automatisch eine Lücke zwischen Defpoint und Beginn der Maßhilfslinie; erzeugt Layer **Defpoints** (plottet nicht).
- Bemaßung auf eigenen **Dims-Layer** in eigener Farbe legen; Linienbreite der Maße beim Plotten **deutlich kleiner** als Objektlinien. Objects-Layer vor dem Bemaßen ggf. sperren (Schutz vor STRETCH etc.).

#### Maßarten
- **Linear (horizontal/vertikal)** — `DIMLINEAR`: erste/zweite Maßhilfslinie + Maßlinienposition; OSNAP/SNAP nutzen. Optionen: Mtext/Text/Angle/Horizontal/Vertical/Rotated.
- **Aligned** — `DIMALIGNED`: Maß parallel zu schräger Fläche (Beispiel 2.8284).
- **Continued** — `DIMCONTINUE`: Folgemaße im gleichen Intervall entlang derselben Kante (nach erstem linear/vertical/aligned).
- **Baseline** — `DIMBASELINE`: alle Maße von einer gemeinsamen Basislinie.
- **Radial** — `DIMRADIUS` (Menü Radius): Radius von Bogen/Kreis; Erscheinung über **Fit-Tab**.
- **Diameter** — `DIMDIAMETER`: gleiche Variablen wie Radius.
- **Angular** — `DIMANGULAR`: Winkel zwischen 2 nichtparallelen Linien oder 3 Punkten, auch Bogen-/Kreissegment; Maßlinie ist ein Bogen.

#### Dimension Styles
- Ein Dimension Style = benannte Sammlung von Einstellungen, die das Aussehen bestimmt (Einheiten-Ausgabe, Textstil, Farbe, Linientypskala u. v. m.).
- **Goldene Regel (wörtlich hervorgehoben): NEVER CHANGE THE STANDARD DIMENSION STYLE.** Immer einen **neuen** Style anlegen (Name eingeben → Save / „Copy of Standard" → Continue).
- Default-Styles: **Standard** (imperial) bzw. **ISO-25** (metric), falls kein Style gesetzt.

##### Text-Tab
- Setzt Textgröße und -position auf der Maßlinie.
- **Mechanische Zeichnungen:** Maßtext **horizontal innerhalb** der Maßlinie.
- **Architektur-/Bauzeichnungen:** Text **über** der Maßlinie und **mit ihr ausgerichtet** (aligned).
- **Texthöhe NICHT** im Text-Tab ändern, sondern im **Fit-Tab** (zusammen mit Pfeilgröße, Lücken, Overshoot, Maßhilfslinien-Abständen — alle müssen gemeinsam stimmen).
- Textstil einfach halten: **Mechanik → Arial**, **Architektur → City Blueprint**; keine Serif-/Script-Fonts für Maßtext.

##### Fit-Tab (Skalierung — zentral)
- Gesamtgröße der Bemaßung über **Overall Scale** im Fit-Tab. Ändern der Overall Scale ändert konsistent Pfeilgröße, Maßhilfslinien-Lücke, Overshoot und Text-zu-Maßlinie-Abstand. Besser Overall Scale ändern als jede Größe einzeln.
- **Maßstab-/Overall-Scale-Tabelle:**

  | Metric | Bedeutung | Overall Scale |
  |--------|-----------|---------------|
  | 1:25  | 1/25 der Originalgröße | 25 |
  | 1:50  | 1/50 der Originalgröße | 50 |
  | 1:100 | 1/100 der Originalgröße | 100 |

  | Imperial | Bedeutung | Overall Scale |
  |----------|-----------|---------------|
  | 1/2" = 1'-0" | 1/24 der Originalgröße | 24 |
  | 1/4" = 1'-0" | 1/48 der Originalgröße | 48 |
  | 1/8" = 1'-0" | 1/96 der Originalgröße | 96 |

- Overall Scale ändern → Maße werden so vergrößert, dass sie im Druck korrekt erscheinen (gleiche Bruchteil-Skalierung wie die Zeichnung selbst). Paper-Space-Bemaßung → Kapitel 11.

##### Primary Units Tab
- Wählt Einheiten-Ausgabe (Fractional, Decimal, Scientific, Architectural u. a.), Präzision, Winkelformat, Rundung, Prefix/Suffix, Measurement Scale (früher **DIMLFAC**), Dezimaltrennzeichen, Zero suppression (Leading/Trailing).

##### Alternate Units Tab
- Zeigt selten benötigt **metrisch UND imperial** gleichzeitig auf der Maßlinie.

##### Symbols and Arrows Tab
- **Center Marks**: Kreise brauchen Mittenmarken (konstanter Radius). Drei Stile: **Mark / Line / None**.
- **Arrowheads**: **Mechanik → Punkte/dots (Closed filled)**, **Architektur → Ticks (Architectural tick)**.

#### Editieren / Speichern von Bemaßungen
- Dimension Styles werden mit der Datei gespeichert und sind übertragbar; Varianten (z. B. „Force line inside", „Best fit") als separate Styles.
- Stile: Text and Arrows / Text only / Arrows only / Leader.
- Editieren: Modify → Properties; nur Text: **DDEDIT**.
- **Prefix** im Primary-Units-Tab: `%%c` für Durchmesserzeichen (Ø) an allen Maßen.
- **Associative dimensions**: Maße sind an Defpoints gebunden → **STRETCH** aktualisiert Maße automatisch. EXTEND/TRIM zur exakten Darstellung.

#### Tutorial 7b — Architectural (Schritt 1–4)
- Grundriss in Architectural Units (`acad.dwt`, Units → architectural), Beispielhaus **25' x 35'**.
- Standard ist 1=1; Grundriss wird in **1/4"=1'-0"** oder **1/2"=1'-0"** gedruckt → eigenen Style nötig. **DO NOT CHANGE THE STANDARD DEFAULTS!**
- Style `Quarter` für 1/4"=1'-0":
  1. Primary Units **architectural**, Präzision **1"** (1/8" oder 1/2" unrealistisch für Grundriss, nur für Details). Rundungsfaktor NICHT ändern (sonst summieren sich Teilmaße auf mehr als das Gesamtmaß).
  2. Text **über** Maßlinie, **aligned**, Offset 0,0900.
  3. Fit-Tab **Overall Scale 48**; Pfeile → **Architectural tick**.
- Layer `Dims`; OSNAP ENDpoint + MIDpoint.
- **Bemaßungsregeln Holzrahmenbau (Frame Building):**
  - Maße sind **für den Zimmermann** → **Außenkante des Rahmens** als Defpoint, NICHT Außenkante der Verkleidung/Veneer.
  - **Fenster und Türen werden zur Mitte (center point)** bemaßt, da die genaue Fenstergröße erst bei Lieferung feststeht.
  - **Innenwände** zur Außenkante der Wand (für Innenmaß) oder manchmal zur Wandmitte.
  - Bei Beton-/Mauerwerksdämmung: Maße üblicherweise von den **Außenkanten**.
- Übungen: Stahlbetonfundament (Maße 1230, 2000, 230, 2300, 920, 530, 1770 mm — Tutorial 14c, S. 276); First-Floor-Plan (Save as, STRETCH für Fenster, Section-Arrow zuletzt); Axle Support (orthografische Projektion, Maße Ø11.00 X THRU, Ø20.00 SFACE 2 holes X2 DP, Ø38, Ø22.00 +0.05/0, 58, 82, R12.0); Crane Hook / Connector (Cast Iron, Fillets .12R, Ø1.125, 2.062 CBORE).
- **Footing and Foundation Drawings**: zeigen Größe des Fundaments und Befestigungen; meist von **Bau-/Statik-Ingenieuren** (nicht Architekten) erstellt.
- **Orthographic Projection**: 3+ Ansichten in 2D im rechten Winkel zueinander; gemeinsame Maße nur auf EINER Ansicht; Symbol bedeutet „Oberfläche zerspant (cut) statt gegossen (cast)".

### Kapitel 8 — Text und perspektivische Ansichten (Anfang, Seiten 158–160)

#### Texterzeugung
- Zwei Grundarten: **Linear Text** (ein/zwei Zeilen) und **Paragraph Text/MTEXT** (längere Einträge). Text im aktuellen Textstil.
- **TEXT / DTEXT**: platzieren Zeichenketten; Prompt für Höhe, Rotationswinkel und Einfügepunkt.
  - Ab Release **2008/2007** funktioniert `TEXT` wie früheres `DTEXT` (vor 2005). Release 2006: nur `TEXT` ohne Mehrzeilen. `TEXT` ist am besten zum Annotieren/Ausfüllen von Schriftfeldern; MTEXT für Absätze/ASCII-Import.

#### Justierungs-Optionen
- `Command:TEXT` → `Specify start point of text or [Justify/Style]`.
- Justify-Optionen: **Align** (durch Endpunkte der Grundlinie, Aspect-Ratio nach Vorgabe), **Center** (Mittelpunkt der Grundlinie), **Fit** (nur Breite anpassen/stretchen zwischen Punkten), **Middle** (um Punkt zentriert, oben/unten + Seiten), **Right** (rechtsbündig).
- Default: **linksbündig an der Grundlinie**.
- Doppelbuchstaben-Justierungen: **TL** top left, **TC** top center, **TR** top right, **ML** middle left, **MC** middle center, **MR** middle right, **BL** bottom left, **BC** bottom center, **BR** bottom right.
- Höhe per Punkt oder Zahl. Beispiel: Center → `height<.2000>:.5`, Rotation `<0>` → „Front Elevation".
- Bei wiederholtem `TEXT` mit `↵` werden Höhe/Rotation übersprungen; neuer Text **direkt unter** der vorigen Zeile.

#### Sonderzeichen-/Steuercodes (TEXT)
- `%%u` underscore (Unterstreichen), `%%o` overscore (Überstreichen), `%%d` degree (°), `%%p` plus/minus (±), `%%c` diameter (Ø), `%%nnn` ASCII (`%%123` = `{`, `%%125` = `}`).
- Beispiel: `%%u%%c25 4 holes` → unterstrichen „Ø25 4 holes".

#### MTEXT-Sonderzeichen (Unicode unter @-Symbol)
- Almost Equal `\U+2248`, Angle `\U+2220`, Boundary Line `\U+E100`, Center Line `\U+2104`, Delta `\U+0394`, **Electrical Phase `\U+0278`**, Flow Line `\U+E101`, Identity `\U+2261`, Initial Length `\U+E200`, Monument Line `\U+E102`, Not Equal `\U+2260`, Ohm `\U+2126`, Omega `\U+03A9`, Property Line `\U+214A`, Subscript 2 `\U+2082`, Squared `\U+00B2`, Cubed `\U+00B3`. Non-breaking Space = Ctrl+Shift+Space.

#### Mehrzeiliger Text — Verhalten
- Neue Zeile richtet sich an der vorigen aus, wenn Basispunkt/Justierung gleich bleiben. Bei `Center` ist alles zentriert, sonst linksbündig.
- **ESC im DTEXT-Befehl löscht den gesamten eingegebenen Text** — immer mit `↵` beenden.
- Text ist ein editierbares Objekt: COPY, MOVE, ERASE, ROTATE, ARRAY; Texteditierung über **DDEDIT, ED, DDMODIFY oder CHANGE**.
