### Kapitel 12 (Forts.) — Paper Space: Beispiel "Haus mit Kamin + Küche" (imperial)
- Zielblatt mit **drei Maßstäben** auf einem Zeichnungsblatt:
  - Grundriss (Plan view) Haus: **1/4" = 1'-0"**
  - Detail Kamin (fireplace): **1" = 1'-0"**
  - Detail Küche (kitchen): **1/2" = 1'-0"**
- AutoCAD-Template-Tipp: Neue Datei → "Architectural English Units" wählen (dann ist kein eigenes Titelblock-Zeichnen nötig). Grundriss in Model Space einfügen (Insert oder Copy/Paste).
- Anzulegende Layer (Name / Farbe):
  - DIM1 / red
  - DIM2 / yellow
  - DIM3 / green
  - BORDER / magenta
  - Pspace / blue
  - Detail / cyan
- **Paper Space öffnen:** BORDER-Layer aktuell setzen → Layout-Tab unten wählen oder Systemvariable **TILEMODE** setzen: `TILEMODE` → neuer Wert `<1>: 0` (führt in den Non-Tiled-Space; Model-Ansicht mit magenta-Rahmen erscheint). Rechtsklick Layout-Tab → Papiergröße setzen; neues Layout "Floor plan" anlegen.
- **Plottergröße** für dieses Blatt: **34 × 22** Zoll. Fehlt ein passender Plotter: per `CONFIG`-Befehl + "Configure a Plotter Wizard" einen Designjet o.ä. konfigurieren (Defaults akzeptieren; Treiber liegt AutoCAD bei). Layout aktuell setzen beim Verlassen.

#### Views (Ansichten) erzeugen mit MVIEW
- Erst in Model Space aktuelle Ansicht auf Maßstab **1:48** zoomen:
  - `Z` → `<real time>: 1/48xp` (1/4" = 1'-0" ≙ Faktor 1/48)
  - alternativ in Paper Space den Rahmen wählen und im Properties-Menü `1/4" = 1'-0"` setzen. **Properties-Toolbar nur in Paper Space nutzbar.**
- Viewport-Größe über die Eck-Grips anpassen (im Paper-Space-Modus Rahmen an der Ecke greifen und ziehen).
- Zwei weitere Ansichten mit `MVIEW` (Optionen: ON/OFF/Fit/Hideplot/Lock/Object/Polygonal/Restore/2/3/4) — je zwei Ecken picken. Jede neue Ansicht zeigt zunächst den vollen Grundriss.

#### Views zoomen (viewport-abhängig)
- Unten rechts: in Model Space toggeln, auf Kamin zoomen, dann `ZOOM` mit xp-Faktor **1/12XP** → 1" = 1'-0".
- Oben rechts: Küche, `ZOOM` **1/24XP** → 1/2" = 1'-0".
- **Regel: ZOOM ist viewport-abhängig.** Zum Zoomen von Objekten in Model Space sein; zum Skalieren über Properties-Menü in Paper Space.

#### Bemaßung der Views
- Neuer Bemaßungs-Stil (Dimension Style) "Pspace" anlegen.
- Unter Reiter **Fit** die "overall scale" auf **0** setzen → skaliert alle Maße auf die jeweilige Ansicht ("Scale dimensions to layout"). Stil current setzen.
- Bei imperialer Zeichnung: Primary Units ebenfalls imperial setzen.
- In Model Space: über Layer-Menü `DIM1` im aktuellen Viewport **frieren (freeze)**, `DIM3` aktuell machen, Raum mit Linear-Bemaßung vermaßen.
- Layer pro Viewport frieren/tauen geht über Layer-Dialog ODER Layer-Pulldown — **muss in Model Space erfolgen**.
- Für Kamin-View analog: `DIM1` frieren, `DIM2` current, vermaßen.
- Im Grundriss-View müssen `DIM2` UND `DIM3` gefroren werden — via Layer-Pulldown (Model Space an) oder Befehl **VPLAYER** (in Paper Space):
  - `VPLAYER` → Option `F` (Freeze) → Layer(s) `DIM3,DIM2` → `S` (Selected) → Planview-Viewport picken.
- **Custom-skalierter Bemaßungs-Layer:** Automatik-Skalierung ist nicht immer optimal. Hier ggf. Bemaßungs-Skala **10** statt Default **12** (Default für diesen Zoom). Neuen Dimension-Stil "fireplace" anlegen, Fit-overall-size = **10**, current; ein Maß setzen, mit "Match properties" die übrigen angleichen.
- Regel/Warnung: Nie mehr als ein paar Einheiten vom Default abweichen, sonst sehen die Maße falsch aus. Wenn man im Vollblatt (Paper Space, ganzes Blatt gezoomt) die Maße lesen kann, sind sie zu groß.

#### Beschriftungen / Notationen + Titelblock
- In Paper Space `pspace`-Layer current. Titel je View mit Schriftgröße **1/4"**. `TEXT` ist hier einfacher als `MTEXT`. Unterstreichungs-Toggle: **%%U**. View-Titel werden immer **unter** der Ansicht platziert.
- Bei gefrorenen Rahmen Break-Lines (Bruchlinien) ergänzen, um anzuzeigen, dass die Wand über den Rahmen hinausläuft — CAD-Zeichnungen müssen dieselben Protokolle wie manuelle Zeichnungen wahren.
- BORDER-Layer global frieren (Freeze in ALL viewports), Layout feinjustieren, Rahmen wieder einblenden, Titelblock einfügen (oder AutoCAD-Architectural-Template nutzen).
- Plotten: `PLOT`-Befehl, Skalierfaktor **1:1**.

### Kapitel 12 (Forts.) — Paper-Space-Beispiel "Footings" (metrisch)
- Zwei Fundamente (footings) auf einem Footing-Layout zusammenstellen:
  - Footing-Layout-Maßstab: **1:500**
  - Footing A: **1:50**
  - Footing B: **1:25** (Footing B = halbe Größe von Footing A → Copy + Scale)
- Metrisches Vorlagenblatt: **acadiso.dwt**. Plot **297 × 210** mm (A4) Querformat (landscape). Eigener Titelblock.
- Layer (Name / Farbe):
  - DIM1 / red
  - DIM2 / yellow
  - DIM3 / green
  - Border / magenta
  - Footprint / blue
  - Pspace / blue
  - Detail / cyan
- Footprint (dunklere Linien) auf Layer Footprint, übrige Details auf Detail. Noch nicht bemaßen.
- **Maße Footing A** (aus Zeichnung): Außenbreite **2000**, innere Abschnitte 230 / 920 / 230; Höhenangabe u.a. 2000; Detailmaße Footing B: 2000, 680, 514.

#### Layout-Grid
- Auf Layer **DIM1**: Raster aus **8 vertikalen** Linien im Abstand **8000** Einheiten und **5 horizontalen** Linien im Abstand **6500** Einheiten. Bubbles (Achs-Kreise) oben und seitlich mit Buchstaben/Zahlen.
- Footings per `COPY` (oder `ARRAY`) auf die Rasterschnittpunkte setzen, **zentriert** auf die Rasterlinien → Basispunkt ist entscheidend. Zwischenspeichern.

#### Paper Space + Viewports (Footings)
- Border-Layer current; `TILEMODE` → `<1>: 0`. Wenn Rahmen nicht magenta ist, ist man nicht im richtigen Layer → Rahmen auf Border-Layer legen.
- Rechtsklick Layout1-Tab → Page Setup Manager → neues Layout "Setup". Plottergröße **8.5 × 11** Zoll bzw. **297 × 210** mm. Plotten ab **1:1** sicherstellen.
- Ersten Viewport einrichten: `MS`, dann `Z` → `<real time>: 1/500xp` (= exakt 1:500). Es gibt keinen Standard-Maßstab dafür im Properties-Manager → Custom-Größe 1:500 via Properties-Toolbar oder ZOOM.
- Viewport-Größe über Eck-Grips: Rahmenkante picken (Grips hervorheben), Ecke ziehen.
- Weitere Ansichten: `MVIEW` (je 2 Ecken). Footing A auf **1/50XP** (1:50), Footing B auf **1/25XP** (1:25); 1:500-Ansicht unten lassen. `M` zum Verschieben. Praktischer: die kleineren Views oben.
- **ZOOM viewport-abhängig** (Wiederholung): Model Space zum Zoomen, Paper Space zum Maßstab-Setzen via Properties.

#### View-Titel (metrisch)
- Pspace-Layer current; `TEXT`. Unterstreichungs-Toggle **%%U**. Titel-Texthöhe **2.5 mm**, Maßstabs-Text **2 mm**.
  - `text` → Höhe `2.5` → Rotation `0` → `%%UFooting A`
  - `text` → Höhe `2` → Rotation `0` → `%%UScale 1:50`
- Titel/Maßstäbe ergänzen für Footing B (1:25) und Layout (1:500).

#### Bemaßung Footings
- Neuer Dimension-Stil "Pspace"; Reiter Fit → **"Scale dimensions to layout"** (skaliert Maße je View). OK, current.
- In Model Space: `DIM1` im aktuellen Viewport frieren, `DIM2` current, Linear-Bemaßung Footing A.
- Footing B: `DIM1` frieren, `DIM3` current, vermaßen.
- Layout-View: `DIM2` und `DIM3` frieren, ggf. auch Detail-Layer frieren. Ggf. **Footprint-Layer frieren** zum sauberen Platzieren der Maße, danach **tauen**.
- Wenn Footprint wieder an: Default-Maßgröße zu groß → Custom-Stil "Fullview", Fit-overall-size = **450** (statt Default **500** für diesen Zoom), current; ein Maß setzen, mit Match Properties angleichen.
- Tipp: danach jede View nochmals re-zoomen auf **1/500XP, 1/50XP, 1/25XP**, falls beim Bemaßen verschoben.
- Konvention: Bei repetitiver Bemaßung (Footing-Bays) nur **ein** Maß setzen, Rest als gleich annehmen. Footings beschriften: A neben alle A-, B neben alle B-Fundamente.
- Border-Layer frieren, Titelblock ergänzen, Plot Skalierfaktor **1:1**.

### Kapitel 13 — POINT, DIVIDE, MEASURE, Inquiry Commands
Lernziele: PDMODE/PDSIZE ändern; DIVIDE/MEASURE zum Setzen von Punkten/Objekten; SPLINE-Befehl; Parameter/Eigenschaften von Objekten prüfen; Gesamtgröße des Modells prüfen; Fläche per AREA/BOUNDARY berechnen.

#### Points, Point Display, Point Size
- Punkte dienen in Spline-Erzeugung, vielen 3D-Anwendungen und als Node-/Referenzpunkte (snapbar/offsetbar). DIVIDE/MEASURE markieren Teilungen mit Punkten.
- Befehl: `POINT`. Default-Anzeige = 1-Pixel-Punkt → für Sichtbarkeit Anzeige ändern.
- **PDSIZE**: positive Zahl = tatsächliche Größe in Zeichnungseinheiten; **negative Zahl** = relativer Prozentsatz des Bildschirms (Zoomfaktor ohne Effekt auf Anzeigegröße).
- Punktgröße/-stil: "Set Size Relative to Screen" oder "Set Size in Absolute Units". Gespeichert in Systemvariable **PDSIZE**. Bestehende Punkte werden bei nächster Regeneration aktualisiert.
- Per MEASURE/DIVIDE oder POINT erzeugte Punkte sind via OSNAP-Option **NODE** ansprechbar (wichtig beim Block-Einfügen an spezifischen Punkten oder in 3D für Fillet-Zentren).
- **Point Style**-Dialog: Format-Menü oder `DDPTYPE`. Ohne Dialog: `PDMODE` für Stil, `PDSIZE` für Größe.

#### DIVIDE
- Befehl: `DIVIDE`. Teilt jedes lineare Element (arc, circle, line, pline) visuell in eine **angegebene Anzahl gleicher Teile** und platziert gleichmäßig verteilte Point-Objekte oder Blocks. Das Objekt selbst wird nicht verändert.
- Mit Punkten: aktuellen Point-Style gut sichtbar setzen → `DIVIDE` → Objekt picken → "Enter the number of segments or [Block]: 6". Punkte werden Objekte; Zugriff via OSNAP NODE.
- Mit Block: z.B. Mullion-Block, der ein Fenster in gleiche Sektionen teilt. Insertion-Point des Blocks = Mitte der Unterkante. Basispunkt sehr wichtig.
  - `DIVIDE` → Objekt picken → `B` (Block) → Blockname `MULLION` → "Align block with object? [Yes/No]" (`Y` = ausgerichtet/rotiert, `N` = ohne Rotation) → Segmente `8`.

#### MEASURE
- Befehl: `MEASURE`. Wie DIVIDE, aber Teilstücke haben eine **angegebene Länge** → es kann ein Rest übrigbleiben. Funktioniert auf lines, arcs, circles, plines; Marker = Punkte oder Blocks.
- Mit Punkten (Beispiel Straße als pline in Lots teilen): Point-Display 4 (vertikale Linie), Länge 18 m via `PDSIZE 18`.
  - `PDMODE` → `4`; `PDSIZE` → `18`; `MEASURE` → Objekt picken → "Specify length of segment or [Block]: 15" → Ergebnis: Straße in **15 m**-Lots, Tiefe **18 m**. (pline hat Linien- und Bogensegmente.)
- Mit Block (Beispiel Toilette entlang Wand): LINE als **19'**-Wand, BLOCK "Toilet" mit Innenmaß **3' × 5'**. Block-Basispunkt so wählen, dass **2"-Wand hinten** und **2"-Abstand seitlich** bleibt.
  - `BLOCK` Name `TOILET`, Insertion base point Ecke; `MEASURE` → linke Wandseite picken → `B` → Blockname `TOILET` → Align `N` → Segmentlänge `1000`.
- Hinweis: Block für MEASURE darf keine überlappenden Elemente haben. Punkte aus DIVIDE/MEASURE werden Objekte → von ERASE/MOVE/COPY betroffen; ohne PDMODE-Änderung evtl. schwer sichtbar.

#### SPLINE
- Befehl: `SPLINE`. Erzeugt glatte Kurven ohne PLINE. AutoCAD nutzt **NURBS** (Nonuniform Rational B-Spline) — glatte Kurve durch Kontrollpunkte, quadratisch oder kubisch. Splines brauchen weniger Speicher/Platz als Polylinien (gut für Mapping/Airfoil).
- Eingabe: erster Punkt (oder `[Object]`), nächste Punkte … bis Enter; Optionen `[Close/Fit tolerance]`. Danach **Start tangent** und **End tangent** angeben.
- `U` (Undo) entfernt den zuletzt gesetzten Punkt (wie LINE/PLINE).
- Start-/End-Tangenz: Tangentialität an erstem/letztem Punkt; OSNAPs point/TANgent/PERpendicular nutzbar (tangential/senkrecht zu bestehenden Objekten).
- **Close**: letzter Punkt deckungsgleich mit erstem, dort tangential.
- **Fit Tolerance**: ändert Toleranz, wie die Spline durch die Punkte verläuft.
- **Object**: konvertiert 2D- oder 3D-Polylinien in Splines.
- **SPLINEDIT** editiert Spline-Objekte (Optionen ähnlich PEDIT).

#### Inquiry Commands (Übersicht)
- Erreichbar über Inquiry-Toolbar oder Tools-Pulldown → Inquiry; auch per Tastatur.
  - **AREA** — Fläche eines geschlossenen Polygons.
  - **DIST** — Abstand zwischen zwei Punkten.
  - **LIST** — listet Position und Eigenschaften eines/mehrerer Objekte.
  - **ID** — identifiziert die Position eines Punktes.
  - **STATUS** — listet alle Datei-Statistiken plus weitere Infos.
- Tastenkürzel im Menü genannt: Command Line `CTRL+9`, Clean Screen `CTRL+0`.

#### AREA
- Berechnet Fläche und gibt zusätzlich den **Perimeter** aus. Nützlich für plines/unregelmäßige Formen.
- Per Entity: `AREA` → `O` (Object) → Objekt picken. Beispiel: `Area = 16.1434  Perimeter = 19.6824`.
- Per Linien/Punkte: Folge von Eckpunkten picken (OSNAP für Genauigkeit), Enter für Summe. Beispiel: `Area = 67.5000  Perimeter = 31.1131`.
- **Add/Subtract** (Netto-Bodenfläche Bad 3 m × 2 m): OSNAP ENDpoint.
  - `AREA` → `A` (Add), Ecken picken → `Area = 6000000  Perimeter = 10000`.
  - Ohne Befehl zu verlassen `S` (Subtract), Fixtures abziehen — Beispiel-Zwischenwerte: Subtrahend `Area = 1859444, Perimeter = 5859` → `Total area = 4140556`; weiter `Area = 306148, Perimeter = 2226` → `Total area = 3834408`; `Area = 139611, Perimeter = 1732` → `Total area = 3694797`; Object-Subtrakt `Area = 199307, Perimeter = 1615` → `Total area = 3495490`.
  - Regel: erst **Add** für erste Fläche, dann **Subtract** für Folgeflächen; Add addiert, Subtract subtrahiert vom akkumulierten Wert.
- `AREA` und `PERIMETER` sind auch **Systemvariablen** (anzeigbar, nicht änderbar) — via `SETVAR` zugänglich; letzte berechnete Fläche per Variablenname `AREA` abrufbar. Länge/Umfang von circle/arc/pline über `LIST`. **Einheiten vor AREA korrekt setzen**, sonst ungenaue Werte.

#### BOUNDARY
- Befehl `BOUNDARY` erzeugt eine **Region** oder eine **Polyline** aus einer geschlossenen Begrenzung. Boundary-Set definieren beschleunigt (weniger Objekte werden untersucht).

#### DISTance
- Befehl `DIST`. Tatsächlicher Abstand zwischen zwei Punkten. Punktangabe auf drei Wegen: (1) via OSNAP (ENDpoint, MIDpoint …), (2) Bildschirm-Pick (mit/ohne SNAP), (3) Koordinateneingabe. Exakte Punkte besser per OSNAP/Koordinaten.
- Ausgabe enthält Distanz, Winkel in der XY-Ebene, Winkel von der XY-Ebene, sowie Delta X/Y/Z. Beispiel: `Distance = 10.2956, Angle in X-Y Plane = 61, Angle from X-Y Plane = 0, Delta X = 5.0000, Delta Y = 9.0000, Delta Z = 0.0000`.

#### LIST
- Listet Layer-, Farb-, Linetype-Eigenschaften. Weitere Zwecke: (1) Objekte vor Hatch/Edit bereinigen, (2) Winkel einer LINE finden, (3) Radius eines Kreises, (4) Textfonts/-größen bestimmen, (5) prüfen ob Items ohne SNAP falsch gesetzt wurden, (6) falsche Bemaßungen prüfen.
- Kann zeigen, ob ein Bemaßungstext **echt oder manuell überschrieben** ist: Im Beispiel zwei optisch gleiche assoziative Maße; LIST zeigt beim zweiten `dimension text modifier: 5.0000`, obwohl aus den Defining Points (Y 8.5000 minus 3.0000) der echte Abstand **5.5000** wäre → Maßtext wurde manipuliert. Properties-Befehl enthält viele LIST-Infos im Dialog.
- LIST + Crossing zeigt Anzahl überlappender Objekte (gut zum Aufspüren doppelter Linien bei Hatch/Bemaßung).

#### ID
- Wie LIST, aber gibt exakte Position eines **Punktes** (statt Objekts). Häufiger in 3D (Z-Tiefe). In 2D zum Orientieren/Bezugspunkt.
- Position relativ zu Ursprung 0,0,0. Punkt im Raum → Z = aktuelle Elevation; Objekt via OSNAP → tatsächliche Z-Tiefe.
- ID als Bezugspunkt für nächste Eingabe mit `@`: z.B. `LINE` → `From point: @2,0` (startet 2 Einheiten in X vom ID-Punkt).
- Zwei Nutzungen: (1) `ID` → Punkt picken → Ausgabe X/Y/Z; (2) `ID` → Koordinaten eintippen (z.B. `23,4,0`).

#### STATUS
- Zeigt Listing aller Datei-Statistiken; auch Infos zu Speicher und Partition, wo die temporäre `.AC$`-Datei liegt. Bei vollem Partition (im Kursraum oft A:-Laufwerk) terminiert das Programm nach vorherigem Speichern. Anfänger nutzen STATUS oft, um zu prüfen, ob die Farbeinstellung die Layer-Farbe überschreibt.

### Kapitel 14 (Beginn) — Attributes für Titelblöcke und Notationen
- **Attribut** = nicht-grafische Information, die als Label/Tag an einen Block gehängt wird; in BOMs, Schedules, Parts Lists nutzbar; in Textformat exportierbar. Für Fill-in-the-Blanks (Notationen, Titelblöcke).
- Bei Attribut-Definition werden Textgrößen, Platzierung und Font festgelegt; der Nutzer füllt nur fehlende Infos (Kunde, Teilname, Datum, Designer …).
- **Block via -INSERT mit Attributen** (Titelblock "TITLE"):
  - `-INSERT` → Blockname `TITLE` → Insertion point `0,0` → X-Scale Enter → Y-Scale Enter → Rotation `0`.
  - Prompts mit Defaults in spitzen Klammern: Customer name `<Skylab Industries>`; Name of Part → `Hook Link`; Datum (Month/Day/Year) → `March 17 2006`; Drawn by `<B. Challis>`; Scale `<1:5>`; Drawing no. `DFC-####<>` → `DFC-1003`.
  - Spitze Klammern enthalten Defaults (Enter = Default übernehmen).
- **ATTDEF** definiert ein Attribut. Dialog: `ATTDEF`; Command-String: `-ATTDEF` (umgeht Dialoge, ebenso `-INSERT`). In Titelblöcken sollte der Font der Block-Titel (Name, Date, Drawn By) sich vom Font der aktuellen Info unterscheiden → neuen Font vorher laden.
- Ablauf `-ATTDEF` (Beispiel Tag "Scale"):
  - Aktuelle Modi: Invisible-N, Constant-N, Verify-N, Preset-N → Option `[Invisible/Constant/Verify/Preset] <done>` (hier keine Änderung).
  - Attribut-**Tag** (ein Wort, Thema): `Scale`.
  - Attribut-**Prompt** (erscheint in der Befehlszeile): `Enter scale of drawing`.
  - **Default-Value**: `1:50` (häufigster gewünschter Wert).
  - Platzierung wie TEXT: `Justify` → `R` (Right) → Höhe `<0.1800>: .25` → Rotation `0`.
- Font-Hinweis: Titelblock-Text in **Standard**-Font; Tag des Scale-Attributs in **Italic Complex Font**; Tag bleibt sichtbar bis die Attribute geblockt werden.
- **Attribute Definition Dialog**: Modi (Invisible/Constant/Verify/Preset), Tag, Prompt, Value (= Default-Value), Text Options (Justification, Text Style, Height, Rotation), Insertion Point ("Specify On-screen"; Dialog verschwindet bis Punkt gewählt). Optionen "Align below previous attribute definition" und "Lock position in block". Wichtig: Referenzpunkt setzen, sonst landet das Attribut irgendwo.
- Nach Definition: Attribute blocken, dann einfügen.
- **Editieren** der Attribut-Definition: `CHANGE` (ohne Dialog) oder Edit-Attribute-Definition-Dialog. Command-Äquivalente: `ED`, `DDEDIT` oder `CHANGE`. `DDEDIT`/`ED` bieten Dialog zum Ändern von Tag, Prompt, Default. `DDEDIT` → ATTDEF-Objekt picken.
