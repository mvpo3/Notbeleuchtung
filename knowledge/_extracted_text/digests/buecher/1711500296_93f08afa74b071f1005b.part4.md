## Inhalt

### Kapitel 8 — Text: Single-Line vs. Paragraph (MTEXT)
- **Paragraph Text / MTEXT**: fuer lange, mehrzeilige Eintraege; alle Absaetze bilden
  **ein einziges Objekt** (kann gemoved, rotiert, kopiert, geloescht, gespiegelt,
  gestretcht, skaliert werden). Default-Text-Befehl unter Draw-Toolbar ab Release 2000.
- Pro Zeichen/Wort/Phrase anwendbar: Overscore, Underline, Fonts, Color, Texthoehe.
- Editor wechselbar ueber Systemvariable **MTEXTED** (Preferences → anderer Editor).
- MTEXT-Befehlsablauf:
  - `Command: MTEXT` → Current text style: STANDARD, Text height: **0.2000**
  - Prompt: `Specify first corner or [Height/Justify/Line Spacing/Rotation/Style/Width]`
  - Breite definieren: (a) gegenueberliegende Ecke picken, oder (b) `W` + Breitenwert;
    **Wert 0** → Text laeuft horizontal bis Return gedrueckt wird.
  - Tabs Properties und Find/Replace bieten weitere Einstellungen.
- Vor Texterstellung **Breite setzen** (wie in Textverarbeitung); Umbruch/Spill nach
  aktueller Attachment-Einstellung; Textgrenze nachtraeglich neu ausrichtbar.
- Manche Fonts werden im Edit-MText-Dialog nicht angezeigt → Ersatz-Font waehlen; nach
  Editieren erscheint Original-Font in der Grafik.

### Kapitel 8 — Textstile und Fonts
- **Text style** = benannter Letter-Stil (vom User benannt); **Font** = Design der
  Buchstaben/Zahlen. Fonts von AutoCAD oder Drittanbietern. Ein Text-Style speichert
  Letter-Stil + Gruppe von Charakteristik-Einstellungen.
- Einfachste Font-Dateien: **Shape-Files / .shx**. True Type Fonts ladbar, aber nicht
  immer fuer Zeichnungsnotation geeignet und **brauchen viel Speicherplatz**.
- Jeder Text-Style nimmt eine Font-Datei aus der AutoCAD-Liste.
- **Default-Style**: `Standard` mit Font `txt.shx`.
- Font laden: Font-Datei nach AutoCAD-Fonts-Ordner kopieren — typischer Pfad
  `C:\Program Files\AutoCAD 2007\Fonts` — dann via **STYLE**-Befehl verfuegbar.
- Hoehe kann im Style-Dialog ODER im Befehl gesetzt werden; **besser in TEXT/MTEXT**
  zuweisen als im Style.
- Neuen Style anlegen: New → Style aus Font-Liste → Apply (lädt) → Cancel wird zu Close
  → Close macht Style current. Standard-Beispielfont: City Blueprint.
- **Width factor** (Beispiele): .5 / 1 / 1.5. **Oblique angle**: 0 / 30 / -30. Weitere
  Optionen: Upside down, Backwards (laut Text selten benoetigt).
- Linien-Anzahl pro Buchstabe (Komplexitaet): **Monotext = 7 Liniensegmente**,
  **Roman Simplex = 19 Liniensegmente**, **English Gothic = 70 Liniensegmente** (Gothic
  ~10x Monotext → fuer Titel, nicht fuer Notation/Bemassung). Fonts mit **TT** = Bitmap/
  Microsoft True Type (nicht aus Linien).

### Kapitel 8 — Text editieren
- Textstring = Objekt: verschiebbar, kopierbar, Layer-/Farbwechsel; aenderbar sind
  String selbst, Hoehe, Rotationswinkel, Style.
- Grips: Paragraph-Text hat Grips an **4 Ecken** der Textgrenze (ggf. am Attachment-
  Punkt); Line-Text hat Grip an **unterer linker Ecke** + Alignment-Punkt.
- Bei OSNAP rastet **INSERT** auf den gewaehlten Insertionspunkt des Textes.
- **CHANGE**-Befehl: aendert Textcharakteristik + String (gut fuer viele Zeilen/Charts).
  Prompts: new TEXT insertion point, new text style (z.B. ROMANT), new height (z.B. 10),
  new rotation angle (z.B. 30), new text. Mehrere Strings → Prompts wiederholen sich.
- **DDEDIT** (Alias `ED`, oder Doppelklick): aendert nur den Textinhalt, nicht
  Formatierung/Properties. Backspace loescht markierten Text.
- **DDMODIFY** / Properties (Modify-Menue): jeweils nur ein String, aber viele
  aenderbare Eigenschaften (analog CHANGE). Auch Justify text / Scale text.

### Kapitel 8 — LEADER (Notationen / Fuehrungslinien)
- **LEADER** (Dimension-Menue): Text mit Fuehrungslinie(n) + Pfeilspitze; Pfeil geht vom
  gepickten Punkt aus.
- Ablauf: leader start point → next point(s) → `[Annotation/Format/Undo]` → erste
  Annotation-Zeile.
- Beispiel-Sondertext: `24.00%%c %%pO.02` (`%%c` = Durchmesser ⌀, `%%p` = ±) → ergibt
  `24.00⌀ ±0.02`. Alle Sonderzeichen nutzbar.
- Pfeilgroesse via Dimension-Style oder **DIMSCALE** / **DIMASZ**.
- LEADER-Optionen:
  - **Tolerance** — Control-Frame mit geometrischen Toleranzen (Geometric-Tolerances-Dialog)
  - **Copy** — kopiert Text/Absatz/Block/Feature-Control-Frame an die Leader-Linie
  - **Block** — fuegt Block am Ende der Leader-Linie ein
  - **Format** — steuert Zeichnung der Leader-Linie + Pfeil (Spline, Straight, Arrow)
- Leader ohne Text: einzelnes Leerzeichen beim Dimension-Text eingeben (gilt fuer alle
  Dimension-Eintraege). `U` macht letzten Punkt rueckgaengig ohne Befehlsausstieg.

### Kapitel 8 — SNAP und GRID
- **SNAP**: rastet auf voreingestellte regelmaessige Intervalle; erlaubt rotierte oder
  isometrische Zeichnung. Setup via **Drafting Settings**-Dialog (Tools-Menue).
- Tutorial-Werte: SNAP und GRID zunaechst auf **.25 Einheiten**.
- SNAP rotieren: `SNAP` → `R` (Rotate) → Base point (z.B. `CEN` eines Kreises) →
  Rotation angle **45**. GRID folgt dem SNAP-Winkel; Crosshairs bleiben senkrecht, aber
  schraeg dargestellt. Zurueck zu Standard: Winkel **0** und Basispunkt **0,0**.
- SNAP/GRID/ORTHO einzeln ein-/ausschaltbar ueber die jeweilige Box.
- GRID/SNAP auch nuetzlich fuer gleichmaessig/abgestufte Bemassungs-Platzierung.

### Kapitel 8 — Tutorial: Titelblock (Title Block)
- Aufbau mit PLINE/LINE; SNAP zum Start auf **.25**.
- Zonen: links unten Scale/Date etc., zentral Firmentitel ("3D Design Studio"), oben
  Revisions.
- Text-Style via **STYLE** (Beispiel-Font **Futura**).
- TEXT/DTEXT fuer mehrere dynamische Eintraege. OSNAP **off**, SNAP **.20**; PLINE-
  Abstand **.40** → Text liegt exakt mittig zwischen den PLines.
- TEXT-Beispiel: height **.1**, rotation 0, Eintraege wie "Scale", "Drawn By",
  "Checked By", "Date", "Date of Print".
- Schriftverkleinerung via **CHANGE** (height z.B. **.08**) + **MATCHPROP** (Properties
  von Quelle auf Ziele uebertragen), dann MOVE.
- Einzeltext via STYLE (Beispiel-Font **CityBlueprint**); fuer Titelbloecke wird Paragraph-
  Text nur fuer grosse Notationen genutzt.
- Beispiel-Eintraege: Scale "as noted", Drawn By "S. Kyles", Checked By "D. Blackman",
  Date 04/01/08, Date of Print 04/21/08.
- Isometrische Beschriftung: SNAP `S` (Style) → `I` (Isometric), vertical spacing → ergibt
  Rotation **30 Grad**. STYLE ROMANT + Oblique angle **-30** fuer Iso-Ebene. Top-Face =
  30° oder -30° Oblique je nach Bottom-Orientierung.
- Center-Text: TEXT → `C` (Center) → Center point → height **.1**.
- Italic-Style fuer Revisions-Notizen (Date/Description).
- MTEXT fuer Datums-/Tender-Absatz; ZOOM All zur Ansicht; mit DDEDIT editieren und unter
  Namen **Titleblock** ablegen → spaeter vor dem Drucken in Zeichnungen einfuegen.
- **Attributes** in Titelbloecken nuetzlich zum Festsetzen von Letter-Groesse, Font,
  Format → einheitlicher Drawing-Standard. Titelblock muss zur Disziplin passen (z.B.
  kein architektonischer Titelblock auf mechanischer Zeichnung).

### Kapitel 8 — Tutorial 8b: Isometrie / POLAR / TRIM (Rabbet-Ecke Holz)
- Neue Datei in **Imperial**; `UNITS` → architectural; isometrischer SNAP/GRID.
- Grid X spacing **1/4"**; bei Iso wird X relativ zu Y; GRID + SNAP beide on.
- **Polar Tracking auf 30 Grad**; POLAR, OSNAP, OTRACK on.
- LINE ab `0,0` mit Polar-Werten (z.B. 6 up, 3 across, 6 down, `c`=close).
- OSNAP-Modi genutzt: **ENDpoint**, **MIDpoint** (Eingabe MID falls kein Dreieck zeigt).
- **TRIM**: Current settings Projection=UCS, Edge=None; cutting edges waehlen → Objekt zum
  Trimmen picken; Optionen `[Fence/Project/Edge/eRase/Undo]`.
- ERASE zum Entfernen einzelner Linien. Tutorial zeigt: SNAP/GRID rotieren, POLAR mit
  Object Snaps auf rotiertem SNAP, TRIM.

- **Cavalier/Cabinet-Projektionen**: bildhafte Ansichten beschreiben Objekt. **Cavalier**:

- **Insulated Concrete Form (ICF)**: Frame 2x6 double top plate; expandiertes Polystyrol

### Kapitel 9 — BHATCH (Boundary Hatch)
- Zweck Schraffuren: Querschnitte / Materialdarstellung. Architektur: Material zeigen
  z.B. brick/stone/wood/concrete/sand.
- **BHATCH** fuellt geschlossenen Bereich mit **assoziativem** Hatch-Pattern (updated bei
  Boundary-Aenderung); erlaubt Preview + Anpassung von Scale/Angle. Dialog-Zugang.
- Befehlszeilen: **`-HATCH`** (Befehlszeile) bzw. **BHATCH** (Dialog). Default-Pattern
  Beispiel: **ANSI31**.
- Bereich muss **geschlossene Boundary** sein ("wie Fluessigkeit" — laeuft sonst aus). Ecken
  mit **FILLET Radius 0** schliessen; ueberlappende Geometrie vermeiden.
- Aelterer **HATCH** (nicht-assoziativ, fuer texturierte Flaechen/dappled light) ab Releases
  2007/2008 unter Options im BHATCH-Menue.

### Kapitel 9 — BHATCH-Dialog Optionen
- **Type**: user-defined vs. AutoCAD-defined.
- **Pattern**: ACAD-Standard-Patterns (Namensliste, Down-Arrow).
- **Swatch**: zeigt Pattern. **Preview**: Vorschau vor Anwendung.
- **Angle**: Pattern-Winkel (generell counterclockwise).
- **Scale**: Default-Scale **1** = berechnet fuer Default-Screen bzw. **11" x 8 1/2"** Blatt.
- **Hatch origin**: Startpunkt fuer Bricks/Stone.
- **Boundaries**: zu schraffierende Objekte (geschlossen oder zusammenhaengend).
- **Options**: Hatches nicht-assoziativ machen.
- **Inherit properties**: wie MATCHPROPERTIES — Scale/Angle eines Hatches auf anderen anwenden.

### Kapitel 9 — Hatch: Layer, Scale, Angle, Boundary
- **Layer-Praxis**: Boundaries auf separatem Layer ablegen + **freeze** → nur Hatch in
  Finalzeichnung sichtbar.
- **Scale**: jedes Pattern hat feste Linien/Zoll. **ANSI31** erzeugt **3 Linien/Zoll bei
  1:1**. Bei Limits/Model > 11 Einheiten in X muss Scale-Faktor geaendert werden.
- Zoll-Einheiten: Hatch-Scale-Faktor = **max. X-Wert des Screens / 12** (= LTSCALE-Faktor).
  Beispiel Limits 0,0 bis 24,18 → Scale-Faktor **2**. Bei Architectural Units = jede Einheit
  ist ein **Zoll**, nicht ein Fuss.
- **Architektonische Patterns sind 12x groesser als mechanische** (siehe Tutorial: ar-conc
  Scale 1 ausreichend). **Immer Preview** vor Anwendung.
- Warnung: ohne Scale-Anpassung versucht AutoCAD Default-Scale → kann Speicher/Diskette
  sprengen → vor Hatching Datei speichern.
- **Angle**: bei Pull-down-Pick erscheint Pattern wie gezeigt. Beispiel **ANSI33** zeigt
  45-Grad — daher Rotation 0 lassen, da 45° die Pattern-Eigengeometrie ist. User-defined
  Patterns: Rotation horizontal berechnet, counterclockwise.
- **Boundary-Probleme** entstehen durch ungenaue Linien/Kreise, mangelhafte SNAP/OSNAP-
  Nutzung (krumme Linien, schlechte Schnittpunkte). Bereinigung: **FILLET Radius 0** oder
  **PEDIT + Join** → durchgaengige Boundary.
- Zwei Wege Boundary identifizieren:
  - **Add: Pick points** — Boundary aus geschlossenen Objekten im Bereich (AutoCAD
    analysiert alle geschlossenen Objekte). Punkt innerhalb Aussen-Boundary aber ausserhalb
    Kreis → Kreis bleibt unschraffiert.
  - **Add: Objects** — Boundary per Objektauswahl (z.B. Fensterauswahl). Geometrie muss
    durchgaengige Boundary bilden.
- **Advanced Options / Object type**: Hatches als **Regions** oder **Polylines**.
- **Remove boundaries**: einzelne Boundaries aus Auswahl entfernen → steuert welche Bereiche
  schraffiert werden. Ergebnis ist **assoziativ** = nur als ein Objekt modifizier-/loeschbar.
- **Solid Hatches** (Releases nach 2006): Solids in welligen Boundaries. Solid-Round-Hatch
  beim Plotten leichter zu berechnen als ein Donut.

### Kapitel 9 — Hatches editieren
- Zwei Wege: (1) Boundaries editieren, (2) Hatch selbst editieren.
- **Boundary editieren**: assoziativer Hatch updated bei Boundary-Aenderung. Hatch folgt
  bei STRETCH/MOVE/ROTATE/MIRROR/SCALE. **Hatch-Layer darf nicht locked sein.**
- **Hatch-Properties editieren**: Doppelklick → BHATCH-Dialog (vor Release 2007: Rechtsklick).
  Beispiele: Pattern von ANSI35 → ANSI38; Scale aendern.

### Kapitel 9 — SKETCH
- **SKETCH**: Freihand-Skizzieren (z.B. Landschaft, rough-edged Sketches, Baeume).
- Maus-Bewegung bestimmt Position; Genauigkeit ueber Increment im Befehl. Kleinere
  Increments → glattere Kurven. Segmente erst bei **Record** gespeichert.
- `Command: SKETCH` → `Record increment <0.01>:` (z.B. .1) → Modus
  `Pen/eXit/Quit/Record/Erase/Connect`.
- Optionen: **R(ecord)** = permanente Aufzeichnung ohne Ausstieg; **Q(uit)** = ohne
  Speichern verlassen; **P(en)** = Pen runter/rauf (toggle, Bewegung wird aufgezeichnet);
  **X(eXit)** = Befehl beenden, alle Segmente behalten; **E(rase)** = wie Backspace ueber
  Segmente; **C(onnect)** = an letztem Endpunkt fortsetzen.
- Warnung: SKETCH erzeugt viele Linien → vor Start Datei speichern.

### Kapitel 9 — GRADIENT
- **GRADIENT**: Finishing-Touch am Ende (wie HATCH); eher Kunst als normaler CAD-Prozess →
  sparsam einsetzen.
- Optionen weitgehend wie BHATCH (geschlossene Boundary → Pattern). Pick points/Select
  objects/Inherit Properties identisch. Assoziativ oder nicht-assoziativ.
- Hauptunterschied: **Farbwahl** (One color/Two color, Shade/Tint, Centered, Angle,
  Orientation).
- Gradients als **Pixel-Adress-Format** (nicht Vektor wie sonst) → viel Speicher, Vorsicht
  beim Plotten; Trial-Plot vor Abgabe.
- Farben sind Designer-Farben; Paletten **RGB (red/green/blue)** und **Pantone**.
- **Druck-Hinweis**: Bildschirmfarben ≠ Druck. Haengt von Aufloesung (dpi) und Paletten ab.
  RGB = Screen-Farben; Druckmaschinen meist auf **CMYK (cyan/magenta/yellow/black)**
  kalibriert; Pantone weicht meist ab. Frueh testdrucken.

### Kapitel 9 — Tutorial: Cavity-Wall-Schnitt (Veneer/Pin/Insulation/Concrete)
- Metrische Datei `acadiso.dwt`; mehrere Layer (Veneer, Pins, Concrete, Insulation, Walls).
- Veneer-Layer braucht durchgaengige Boundary; Bereich des Pins gehoert zum Concrete-Layer,
  nicht Pin-Layer. Insulation-Layer zwischen Veneer und Concrete. Masse u.a. **400**.
- Arbeitsweise: alle Layer ausser Ziel-Layer freezen, dann hatchen.
  - **Veneer**: ANSI31, **Scale 10**, Add Select objects (Fenster). Falsche Ecken → jeden
    Brick einzeln umfenstern, fehlerhafte Ecke finden.
  - **Insulation**: eigener Insulation-Hatch; alle Rechtecke geschlossen, FILLET Radius 0.
  - **Concrete**: Concrete-Layer thawen; Pin-Layer zeigt Pin von Aussenkante des Betons;
    Concrete-Boundary durchgaengig mit ausgespartem Pin-Bereich. Pattern **ar-conc**
    (architectural concrete), Scale **1** (architektonisch 12x groesser); Pick points.
  - **Wall-Section + Drywall**: Break-Line an Wand-/Insulation-/Veneer-Enden vor dem Hatchen
    setzen (in Construction Drawings zeigt Break-Line gebrochene Enden). Eigener Drywall-Layer.
- Detail: Betonsaeule mit duenner Aussen-Insulation, Veneer (Brick/Decorative-Concrete-Block)
  an Saeule + Wand gepinnt, Innenfinish Drywall.

### Kapitel 10 — Blocks und Wblocks (Beginn)
- **Block** = Sammlung/Set von Objekten unter einem Namen; einmal geblockt → vielfach
  einfuegbar. Spart Designzeit bei grossen Projekten.
- Zwei Typen: **Internal Block** (Befehl BLOCK; Teil der Basiszeichnung, nur darin zugreifbar)
  vs. **External Block / Wblock** (eine .DWG-Datei). Jede Zeichnungsdatei ist bereits ein
  externer Block und jederzeit einfuegbar.
- Dimensions und Hatches gelten ebenfalls als Blocks (Info-Gruppen), aber nicht mit BLOCK-
  Befehlen erstellt.
- Die sechs Block-Befehle:
  - **BLOCK** — erzeugt internen Block
  - **WBLOCK** — erzeugt .DWG-Datei / externen Block
  - **INSERT** — fuegt Block oder Wblock ein
  - **MINSERT** — fuegt Blocks in rechteckigen Arrays ein (wie ARRAY)
  - **BURST** — wandelt geblockte Daten zurueck in Einzelobjekte
  - **EXPLODE** — wandelt geblockte Daten zurueck in Einzelobjekte
- **BLOCK-Befehl**: drei Angaben noetig — **Name**, **Insertion Base Point**, **Objekte**.
  `-BLOCK` = ohne Dialog (schneller). Hyphen-Praefix `-` schaltet Dialoge generell ab.
  Beispiel: `-BLOCK` → Name `STENO` → Base point `MID of (pick)` → Objekte. Bei `-BLOCK`
  verschwindet der Block vom Screen; mit Dialog wechselt er nur die Farbe.
- **Insertion Base Point** = Referenzpunkt fuers Einfuegen (wie Base point bei COPY/MOVE);
  logisch aufs Objekt setzen → perfektes Einfuegen. Falsch gesetzt → EXPLODE + reBLOCK.
- **INSERT-Befehl**: platziert definierten Block in Originalgroesse. **X-Scale Default 1**;
  **Y-Scale Default = X**. X=2 → Y auch 2 (ausser geaendert); Y relativ zu X aendern verzerrt
  das Bild. Rotation = counterclockwise um Insertion Base Point.
  - Ablauf `-INSERT`: Block name → Insertion point `[Scale/X/Y/Z/Rotate]` → X scale factor
    `<1>` → Y scale factor `<use X>` → rotation angle `<0>`.
  - Insert wie COPY, aber Objekt per Name statt Pick.
  - **Browse**-Option (Insert-Dialog): externe Blocks einfuegen (Liste aller Drawings auf
    C:/D:/Floppy). Down-Arrow → interne/bereits genutzte Blocks.
  - Externe Blocks = bereits erstellte AutoCAD-Files (Titelbloecke, Drawing-Arrows, Sections,
    Notationen, mehrfach genutzte Views) zum Zusammenstellen finaler Zeichnungen.
  - Beispiel: `-INSERT` → `a:title` (Titelblock von Laufwerk A einfuegen).
