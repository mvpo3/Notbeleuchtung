Dieses Dokument ist ein **AutoCAD-Lehrbuch** (vermutlich "Engineering Drawing with AutoCAD" o.ae., Release 2006–2008, imperiale + metrische Masse). Teil 7 deckt das **Kapitel 14 "Attributes"** (Block-Attribute, Datenextraktion, Bill-of-Materials, Titelbloecke) sowie den **Stichwortindex** des Buches ab. Es enthaelt **kein** oesterreichisches Norm-/OVE-/OENORM-Elektroplanungswissen — es ist reines CAD-Bedienwissen. Der einzige elektrofachliche Hinweis: bei Attributen in **elektrischen Zeichnungen** muessen Attribute sichtbar/lesbar sein, daher Blocks fuer beide Drehrichtungen anlegen.

## Inhalt

### Attribut-Definitionen aendern (CHANGE / DDEDIT)
- CHANGE und DDEDIT veraendern die **Attribut-Definitionen**, nicht den bereits attributierten (geblockten) Block.
- Der Dialog "Edit Attribute Definition" bietet drei Eingabefelder: **Tag**, **Prompt** (Eingabeaufforderung) und **Default** (Standardwert; hier "Default" genannt). Mit OK bestaetigen.

### Attribute blocken (BLOCK)
- Sind alle Attribute definiert, muss die Information mit **BLOCK** zusammengefasst werden.
- Attribut-Definitionen in der **gewuenschten Reihenfolge der Prompts einzeln picken**. Bei Verwendung von **Window** kann die Abfrage in **umgekehrter Reihenfolge** erfolgen.

### Attributierte Blocks einfuegen (INSERT / -INSERT / ATTDIA)
- Nach Erstellung mit **INSERT** auf der Zeichnung platzieren. Der eingefuegte Block enthaelt die Werte jeder einzelnen Instanz.
- **-INSERT** → Abfrage auf der Kommandozeile.
- **INSERT** → Insert-Dialogbox.
- **ATTDIA** steuert die Attribut-Dialogbox beim Einfuegen. Erscheint die Box nicht, ATTDIA einschalten:
  - `Command:ATTDIA` → `Enter new value for ATTDIA<0>:1`

### Attribut-Definitionen waehrend des Einfuegens korrigieren
- Fehler in Block-Definitionen: **EXPLODE** den attributierten Block, dann **CHANGE** oder **DDEDIT**.
- Beim EXPLODE faellt der attributierte Block zurueck ins **Tag-Format**.

### Beispiel Titelblock (Figure 14.3, BEACH DESIGNS / COMPUTER AIDED DESIGN SERVICES)
- Links: Grafik mit Attribut-Tags vor dem Blocken. Rechts: eingefuegter Block mit Instanzwerten.
- Beispielwerte der Instanz: Customer = Skylab Industries, Drawn = B. Challis, Part = Hook Link, Scale = 1:500, Date = March 17 2008, Drwno = DFC-1003.
- Default-Werte nach Eingabe aendern: EXPLODE, dann CHANGE oder DDEDIT.

### Attribute anzeigen (ATTDISP)
- Attribute koennen **universell unsichtbar** gemacht werden via Invisible-Mode im **ATTDEF**-Befehl, oder spaeter via **ATTDISP**.
- ATTDISP ist nur auf der Kommandozeile verfuegbar:
  - `Command:ATTDISP` → `Enter attribute visibility setting [Normal/ON/OFF] <Normal>:`
- Werte:
  - **ON** = alle Attribute sichtbar
  - **OFF** = alle Attribute unsichtbar
  - **Normal** = normale Sichtbarkeit, individuell gesetzt

### Attribut-Modi (Attribute Modes)
Damit Blocks ohne Display-Abschaltung eingefuegt werden koennen, Modus auf invisible setzen. Vier Modi:
- **INVISIBLE** — macht alle Attribute unsichtbar.
- **CONSTANT** — macht ein Attribut uneditierbar (z. B. "president's desk" bleibt immer "president's desk", auch wenn der Praesident wechselt).
- **VERIFY** — erlaubt einen finalen Kontrollblick auf das Eingegebene, bevor es der Zeichnung hinzugefuegt wird.
- **PRESET** — fuer Attribute, die immer denselben Wert haben.

### Attribute fuer Datenextraktion erstellen
- Attribute fuer zwei Zwecke: (1) Titelbloecke / Zeichnungsbeschriftungen; (2) Information zum Download in Preisliste oder Stueckliste (Bill of Materials).
- Definition immer gleich; Extraktion erfolgt erst, wenn alle attributierten Blocks eingefuegt sind.
- Bei **Zeichnungsbeschriftungen**: Attribute fast immer sichtbar.
- Bei **Stueckliste / Parts-List / Schedule**: Attribute meist unsichtbar auf der Zeichnung, aber in der Attribut-Extrakt-Tabelle gezeigt.
- Attribute sind **immer mit Blocks verknuepft**. Fuer einen attributierten Block: zuerst die Geometrie des finalen Blocks erstellen (falls vorhanden), dann Attribute hinzufuegen. Ein Titelblock braucht Linien + Text + Attribute; ein Block, der z. B. nur Raumfarben extrahiert, braucht keine Geometrie.
- Konzepte fuer Nicht-Computer-Nutzer relativ schwierig; nur Uebung hilft (drei Tutorials am Kapitelende).

### Attribute editieren (ATTEDIT / Enhanced Attribute Editor)
- Zwei Wege: einzeln oder in Gruppen.
- **Einzeln**: ATTEDIT oder Enhanced Attribute Editor → Block waehlen → Tabs:
  - Tab 1: Wert des Attributs aendern.
  - Tab 2: Groesse und Qualitaet des Texts.
  - Tab 3: Eigenschaften (Layer, Color, Linetype).
- **Global (Figure 14.4)** via Kommandozeile:
  - `Command:-ATTEDIT`
  - `Edit attributes one at a time? [Yes/No]<Y>:N`
  - `Performing global editing of attribute values`
  - `Edit only attributes visible on screen? [Yes/No]<Y>:` (Enter)
  - `Enter block name specification <*>:JIGLEG`
  - `Enter attribute tag specification <*>:Material`
  - `Enter attribute value specification <*>:` (Enter)
  - `Select Attributes:` (pick 1, pick 2)
  - `Enter string to change:Steel`
  - `Enter new string value:Bronze`
- **WICHTIG: Werte sind case-sensitive** — "Steel" funktioniert, "STEEL" nicht. Korrekt tippen.
- Alternative bei vielen Aenderungen: Block **EXPLODE**, neu definieren, unter gleichem Namen **re-blocken** → alle Block-Instanzen werden aktualisiert.

### Datenextraktion (ATTEXT / EATTEXT)
- **ATTEXT** druckt die Datei in ein Spreadsheet oder eine Materialliste aus, ohne die Zeichnung zu veraendern. Ziel-Apps: Excel, Lotus 1-2-3, Textverarbeitung. Export oder direkte Ausgabe auf die Zeichnung via **EATTEXT**.

#### ATTEXT und Template-Dateien
- Zum Extrahieren mit ATTEXT muss eine **Template-Datei (.txt)** erstellt werden (Wordpad oder Notepad).
- Template-Beispiel (Tag + Code-Spalte):
  - `PARTNO   C008000`
  - `DESCRIPT C015000`
  - `MATERIAL C008000`
  - `SIZE     C008000`
  - `PRICE    C008000`
- Aufbau einer Zeile = **Tag + Code**, z. B. `PARTNO C008000`:
  - **C** = character (Zeichenfeld)
  - **008** = max. 8 Zeichen im Feldnamen (z. B. C008000)
  - **000** = Anzahl Dezimalstellen (bei Zeichenfeldern keine noetig)
- Nach Erstellung ATTEXT aufrufen → Attribute-Extraction-Dialogbox. Template-Datei = die eben erstellte; Extract-Datei = die zu erzeugende; Ansicht in Wordpad/Notepad.

#### EATTEXT
- **EATTEXT** = kompilierte Auflistung der Attribute am Bildschirm; fuehrt durch den Extraktionsprozess und platziert die Daten auf dem Schirm.
- Neuer Befehl mit **Release 2006**. In **Release 2008** komplizierter: beim Prompt **alle Referenzen auf Objekte ausser Attributen entfernen**, dann funktioniert es.
- Abfrage u. a. nach einer Tabellen-Ueberschrift (Beispiel: "Jig Assembly"). Listen koennen nach jedem beliebigen Tag nummeriert werden.
- Beispiel-Extraktion (Figure 14.5, Spalten: hardware/Quantity, DESCRIPT, MATERIAL, Name, PARTNO, PRICE, PRODNO, SIZE):
  - Jig Leg · Bronze · J1 · JIG135 · 5.26 · .60 x 1.25
  - Jig Leg · Steel · J1 · JIG135 · 5.26 · .60 x 1.25
  - Jig Leg · Bronze · J1 · JIG125 · 5.26 · .60 x 1.25
  - Stand. Bushing · Steel · B1 · BU135 · 3.29 · .125 x .55
  - Stand. Bushing · Steel · B1 · BU125 · 3.29 · .125 x .55
  - Jig Leg · Steel · J1 · JIG125 · 5.26 · .60 x 1.25

### Tutorial 14a — Attributierter Titelblock
- **Step 1**: Mit LINE und PLINE einen Standard-Titelblock zeichnen; TEXT fuer die Ueberschriften je Bereich. Imperiale oder metrische Masse.
  - Titelblock auf einen **Layer "title"** legen. Auf **Layer 0** wuerde er Linetype/Layer/Color des aktuellen Layers der empfangenden Datei beim Einfuegen uebernehmen.
  - Beispielmasse: 6.00 [1523], 3.00 [76], 1.50 [38].
- **Step 2**: Attribut-Definition fuer das Datum. Erst mit **STYLE** einen neuen Textstil "attributes" mit anderer Schrift setzen. Dann getippte ATTDEF-Variante:
  - `Command:STYLE` (neuer Textstil "attributes", andere Font)
  - `Command:-ATTDEF`
  - `Current attribute modes:Invisible-N Constant-N Verify-V Preset-P`
  - `Enter an option to change [Invisible/Constant/Verify/Preset] <done>:` (Enter)
  - `Enter attribute tag name:Date`
  - `Enter attribute prompt:Enter today's date`
  - `Enter default attribute value:` (leer)
  - `Justify/Style/<start point>:J`
  - `Align/Center/Fit/Middle/Right/TL/TC/TR/ML/MC/MR/BL/BC/BR:R`
  - `Right point:` (pick 1)
  - `Specify height <5.0000>: .15`
  - `Specify rotation angle <0>:` (Enter)
- **Step 3**: Attribut fuer den Zeichner via Attribute-Definition-Dialogbox. Modi (Invisible/Constant/Verify/Preset), Insertion Point "Specify on-screen", Tag/Value, eigenen Namen als Default. Optionen: "Align below previous attribute definition", "Lock position in block".
  - Hinweis: Sitzt das Attribut falsch, war der Insertion-Point-Bereich falsch gesetzt — Undo und erneut, dabei Insertion point zuerst aus dem Dialog waehlen (on-screen).
- **Step 4/5**: Restliche Attribute (Customer, Drawn, Part, Scale, Drwno) per Kommandozeile oder Dialog definieren, damit jeder Bereich ein Tag hat. Danach kann der Titelblock in andere Zeichnungen eingefuegt werden. Datei unter **Title1** speichern (`Command:SAVE TITLE1`), Verzeichnis beachten (Notfalls A:-Laufwerk / Flash-Drive).
- **Step 6**: Neue Datei, Block testen (Dialog oder Kommandozeile). Title1 offen lassen.
  - `Command:New`
  - `Command:-INSERT` → `Enter block name or [?]:TITLE`
  - `Specify insertion point or [Scale/X.../PRotate]:0,0`
  - X-Scale (Enter), Y-Scale (Enter, = X), Rotation <0> (Enter)
  - `Customer name <Skylab Industries>:` (Enter)
  - `Name of Part <>:Hook Link`
  - `Enter the current date (DD/MM/YY):17/03/06`
  - `Drawn by <S.R.Kyles>:Bill Challis`
  - `Scale <1:50>:` (Enter)
  - `Drawing no. DFC-####<>:DFC-1003`
- **Step 7**: ATTDIA einschalten fuer Dialog-Eingabe der Attribute:
  - `Command:ATTDIA` → `Enter new value for ATTDIA<0>:1` → OK platziert sie.
  - Tipp: Mitstudent den Block einfuegen lassen, ohne Hilfe — versteht er die Prompts nicht, Prompts ueberarbeiten.
- **Step 8 (Justierung/Aufraeumen)**:
  - Textgroessen / Justifizierungen anpassen via CHANGE, DDEDIT oder Properties-Menue.
  - `Command:-justifytext` → Select objects (Text picken) → Enter.
  - Fuer Justierung mancher Attribute (z. B. "Skylab Industries", "DFC-1003") helfen weder CHANGE noch DDEDIT — stattdessen die **Properties-Leiste** unter Modify verwenden (Position X/Y/Z, Layer ByLayer, Linetype, Plot style ByColor, Thickness 0.00, Contents DATE, Justify Left, Height 3.5, Rotation 0, Width factor 1.00, Obliquing 0, Text alignment 0.00).
  - Nach Aenderung speichern und neu einfuegen.
  - Bleiben Probleme trotz Update/Resave/Reinsert: Title1-Block loeschen, dann **PURGE** aus dem Speicher entfernen (manchmal wird die alte Datei statt der neuen geladen). PURGE-Dialog: "Confirm each item to be purged", "Purge nested items", Kategorien Blocks/Dimension styles/Layers/Linetypes/Mline styles/Plot styles/Shapes/Table styles/Text styles. `Command:PURGE`.

### Tutorial 14b — Jig mit Bushing und Jigleg (Bill of Materials)
- Kontext: in der Fertigung werden Teile wie Bushings eingekauft statt vor Ort gefertigt; Bestellinfo als Attribute mit dem Block speichern.
- **Step 1/2**: Teile in imperialen Massen zeichnen, **separate Layer** fuer Bushing und Jigleg. Beispielmasse u. a. 6.00, 3.00, R0.30, O0.15, O2.00, O0.30, R0.25, O0.40, O2.50, O0.60, O0.50, O3.50.
  - BOM-Info: Part Number, Description, Material, Size, Price (+ spaeter Quantity). Wird als Attribute zum Block hinzugefuegt, dann extrahiert. Die Woerter in der Illustration sind Attribut-Tags, kein Text — kein Text noetig.
  - Jigleg-Attribute (Tag / Prompt / Default Value):
    - Partno / Enter Part Number / **JIG125**
    - Descript / Enter Part Description / **Jigleg**
    - Material / Enter Material / **Steel**
    - Size / Enter Part Size / **.60 x 1.25**
    - Price / Enter Current Price / **5.26**
  - Eingabe via `-ATTDEF` (Jig), z. B.:
    - `Enter attribute tag name:PARTNO` / `Enter attribute prompt:Enter Part Number` / `Enter default attribute value:JIG125`
    - `Justify/Style/<start point>:` (Spot neben dem Teil picken) · `Specify height <5.0000>: .03` · Rotation <0> (Enter)
  - Bei der naechsten Zeile richtet sich die Attribut-Definition an der zuletzt eingegebenen aus, wenn man an der Justify-Zeile Enter drueckt oder im Dialog OK waehlt → perfekte Ausrichtung. Enter bringt den vorigen Befehl zurueck (schnelleres Definieren).
- **Step 3**: Block des Teils mit neuem Namen erstellen:
  - `Command:-BLOCK` → `Block name (or ?):ATTJIGLG`
  - `Insertion base point:CENter of` (pick 1)
  - `Select objects:` (pick 2, 3) — der Block verschwindet danach.
- **Step 4**: Gleiches fuer das Bushing via Dialogbox. Werte:
  - Partno / Enter Part Number / **BU125**
  - Descript / Enter Part Description / **Stand. Bushing**
  - Material / Enter Material / **Steel**
  - Size / Enter Part Size / **.125 x .55**
  - Price / Enter Current Price / **3.29**
  - Dialog via ATTDEF tippen oder Draw-Menue → Block → Define Attributes. Nach der ersten Definition Button "Align under previous definition" picken, damit Definitionen fluchten.
- **Step 5**: Mit BLOCK-Dialog Geometrie + Attribute als Block speichern (Name z. B. **Bushing125**, Unitless). Optionen: Scale uniformly, Allow exploding, Select objects, Retain/Convert to block/Delete, Base point "Pick point".
  - **Wichtig**: Insertion-Base-Point **picken** — wird nicht abgefragt, oft vergessen; Default 0,0 macht das Platzieren der Bushings schwierig.
- **Step 6**: ZOOM All → Originaldatei zurueck. Vier Kreise fuer die Jiglegs **0.50 vom Rand** in jeder Ecke; vier Kreise am QUADrant des Mittellinien-Kreises innen. Vier Jiglegs + vier Bushings einfuegen:
  - `Command:-INSERT` → `Block name (or ?):ATTJIGLG`
  - `Insertion point:CEN of` (pick 1) · X-Scale <1> (Enter) · Y-Scale (=X) (Enter) · Rotation <0> (Enter)
  - Attribut-Prompts mit Defaults bestaetigen (JIG125, Jigleg, Steel, .60 x 1.25, 5.26).
  - Fuer alle vier: dreimal weiter einfuegen ODER bestehenden Block kopieren.
- **Step 7**: Letzte vier Teile via Attribut-Dialogbox. Bushings einfuegen und **jedes um 90 Grad drehen** zum korrekten Fluchten. INSERT-Dialog: Name/Path/Browse, Rotation Angle (Specify on-screen), Uniform Scale, Insertion point (Specify on-screen), Explode.
  - **Wichtiger Elektro-Hinweis**: Beim Einfuegen werden Attribute **mit der Geometrie mitgedreht**. Bei Mechanik/Architektur unwichtig (Attribute meist nicht geplottet). In einer **elektrischen Zeichnung** muessen Attribute jedoch **sichtbar und lesbar** sein — in diesem Fall **attributierte Blocks fuer beide Drehrichtungen** anlegen.
- **Step 8**: Wenn nur eine Zeichnung: ATTDISP nutzen, alle Attribute ausschalten — `Command:ATTDISP` → `Normal/On/Off <current value>:OFF`.
- **Step 9**: Attribut-Tabelle (Bill of Materials) via **EATTEXT** erstellen, Menues folgen.
