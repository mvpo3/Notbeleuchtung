## Inhalt

### Kapitel 10 — Blocks und Wblocks

**Block-Grundbegriffe**
- Einmal eingefügter Block/Drawing = „block instance" (Gummistempel-Prinzip: Original bleibt im Speicher, Kopie wird in aktuelle Zeichnung gelegt).
- Beim Einfügen werden ALLE zugehörigen Layer, Dimension Styles und Text Styles in die Empfangsdatei mitkopiert.
- `BLOCK`-Befehl erzeugt **interne Blöcke** — existieren nur innerhalb der Zeichnung, von außen nicht zugreifbar.

**WBLOCK-Befehl**
- `WBLOCK` erzeugt eine **separate `.dwg`-Datei** aus einem Teil der aktuellen Zeichnung = **externer Block**.
- Regel: WBLOCK sollte NICHT zuerst mit BLOCK geblockt werden.
- Nur über Kommandozeile zugänglich. Syntax:
  - `Command:-WBLOCK`
  - `Enter name of existing block or [=(Block=output file)/*(whole drawing)] <define new drawing>:`
  - `Block name (or ?):A:NORTH`
  - `Specify insertion base point:` (pick)
  - `Select objects:` (pick)
- Beim Dateinamen IMMER Laufwerk/Verzeichnis mitangeben, sonst landet WBLOCK im Default-Verzeichnis.
- Einfügen einer externen Datei in andere Zeichnung mit `-INSERT` bzw. Insert-Dialog. Der eingefügte Block bringt seine Layer/Dimstyles/Textstyles unverändert mit.
- WARNUNG: Wenn man einen **existierenden Block** mit demselben Namen wblockt, wird die Datei unbrauchbar — AutoCAD findet sie nicht. Immer vorher explodieren oder anderen Namen verwenden.

**Copy/Paste vs. WBLOCK (wichtiger Unterschied)**
- Copy ist globaler Computer-Befehl (Edit-Menü, `CTRL+V` für Paste, `CTRL+SHIFT+V`, `CTRL+A`); der AutoCAD-`COPY`-Befehl (Modify-Menü) ist NICHT dasselbe.
- „Copy with Base Point" zum Ausrichten mit der Empfangsdatei verwenden.
- **WBLOCK**: Daten als geschlossene Einheit; nichts im Block wird durch Parameter der Empfangsdatei verändert (Bemaßung erscheint exakt wie im Original).
- **Copy/Paste**: Bemaßung wird auf die Parameter der Empfangsdatei aktualisiert (Dimension Style „Furniture", Layer „DIM" der Zieldatei greift); kein Block, keine Datei im Verzeichnis, alle Objekte einzeln; Textstil wird in beiden aktualisiert.
- Merke: Eine Datei ist kein Block, bis sie in eine andere Datei eingefügt wird. Man muss eine Zeichnung NICHT blocken, um sie in eine andere einzufügen.

**Einfügen vorhandener Zeichnungen / Basispunkt**
- Default-Basispunkt eingefügter Zeichnungen = Ursprung `0,0`.
- Mit `BASE` im Original einen anderen Insertion-Base-Point definieren.

**MINSERT-Befehl**
- Fügt mehrere Block-Instanzen in **rechteckigem Array** ein (kombiniert INSERT + ARRAY). Nur über Kommandozeile.
- Parameter: `Specify rotation angle <0>:90`, `Enter number of rows <1>:3`, `Enter number of columns:6`, `Enter distance between rows:4'`, `Specify distance between columns:5'`.
- MINSERT-Blöcke können NICHT einzeln editiert/explodiert werden — löscht man einen, löscht man alle.

**Editieren / EXPLODE / BURST**
- Ein Block wird als einzelne Entität behandelt; ein Pick wählt den ganzen Block.
- `EXPLODE` reduziert ein Objekt auf seine Ursprungselemente: Block → Linien/Bögen; Polyline/Polygon → Linien-/Bogensegmente; Dimension → Linien, Pfeilspitzen, Text.
- Titelblöcke meist nur mit allgemeinen Infos (Maßstab, Datum) gespeichert; zum Ändern `EXPLODE` dann `DDEDIT`.
- `BURST` arbeitet wie EXPLODE, lässt aber Attribute als „values" statt „tags" zurück. BURST nicht in allen Release-2006-Versionen verfügbar.

**Blöcke aktualisieren (redefine)**
- Pro Name nur EINE Blockdefinition je Datei. Ändert/aktualisiert man das Original, aktualisieren sich ALLE Instanzen.
- Redefine-Workflow: `-BLOCK` → Name → `Block STENO already exists. Redefine it?<N>:Y` → Basispunkt → Objekte wählen → alle Instanzen werden aktualisiert.

**Layer 0, ByBlock/ByLayer, Farbe/Linetype**
- Default-Layer ist **0**, kann nicht umbenannt/gelöscht werden (universeller Layer, intensiv für ByBlock/ByLayer-Einstellungen von Color/Linetype genutzt).
- Objekte auf Layer 0 nehmen beim Einfügen automatisch den aktuellen Layer der Zeichnung samt dessen Farbe/Linetype an.
- Sind Color/Linetype nicht „by layer" gesetzt, überschreibt die aktuelle Einstellung die Layer-Einstellung. Prüfen mit `STATUS`.
- Objekte auf anderem Layer als 0 in einem Wblock: diese Layer werden beim Einfügen der Liste der aktuellen Datei hinzugefügt.
- Soll ein Wblock immer festen Layer/Linetype/Color haben → explizit zuweisen, NICHT auf Layer 0 lassen.
- Im Zweifel `0,0` als Insertion Point; bei 1:1-Erstellung passen die Daten immer.

**PURGE-Befehl**
- Jedes Einfügen legt eine Kopie im Drawing-Memory ab; zum Säubern `PURGE`.
- `PURGE` löscht alle ungenutzten Blocks, Layers, Text Styles, Linetypes etc. aus den Datei-Defaults.
- Syntax-Optionen: `[Blocks/Dimstyles/LAyers/LTypes/PLotstyles/SHapes/textSTyles/Mlinestyles/All]` → z. B. `A`, dann `Enter names to purge <*>:`.

**DesignCenter & Dynamic Blocks**
- `ADCENTER` oder `Ctrl+2` öffnet das Design Center mit umfangreicher Block-DB (Kategorien unter Folders-Tab). Alle Blöcke 1:1 gezeichnet, mit logischem Insertion-Base-Point; teils dynamische Blöcke.
- **Dynamic Blocks** (ab Release 2006): flexible Blöcke, beim Platzieren dimensionierbar (Tür, Fenster, Bolzen etc.), über „Block Edit"-Icon erstellt.

**Tutorial-Kennwerte (Kap. 10)**
- Start metrisch mit `STARTUP`/`acadiso.dwt`, Layer „Dims" und „Objects".
- Stuhl-Block: Center des unteren linken Kreises auf `0,0`; Dimension Style „Furniture": Overall scale 10 (Fit-Tab), 2 Dezimalstellen (Primary Units).
- Esstisch 1800 mm × 1250 mm; Stühle drumherum mit MIRROR/ROTATE (180°-Rotation → Maße rückwärts).
- Titelblock-Datei „Chap10title": Außenlinie = Umriss eines 297 × 210 mm Papiers, Titelblock passt hinein. Maßstab für diese Zeichnung 20 → gedruckt erscheinen Tisch/Stühle in 1:20. Vernünftige Maßstäbe 1:10/1:20, nicht 1:17.
- WBLOCK-Test: „TESTCHAIR"; Textstil „Label" Font GothicE; `U` (Undo) holt Daten zurück, erhält aber die wblockte Datei.
- Backup-Empfehlung bei redefine: alle paar Stunden, drei Kopien.

**Block-Übungen (Kap. 10)**
- Mechanik: Template, Bushing, Jiglegs erstellen/blocken → zur Baugruppe zusammenfügen. „Assembly drawing" zeigt alle Teile montiert; Teilbaugruppe = „sub-assembly".
- Architektur (Brian-McKibbin-Gebäude): Schnitt/Details für Elevation; Werte aus Zeichnung: 100 mm Beton, 200 mm Gravel/Schotter, Section-Maßstäbe 1:20 / 1:25; Stockwerksmaße u. a. 3796, 1360, 1400, 3990, 3990. Gebäude 10 m breit. Elevations geben wenige Maße; Höhen aus Section-Views, Teilgrößen (z. B. Gesims) aus Detail-Drawings.

### Kapitel 11 — Setting Up Drawings and Plotting (Maßstab & Plot)

**Grundprinzip Maßstab**
- Alle AutoCAD-Zeichnungen bei **1:1** zeichnen; Dimensionen, Notationen, Titelblöcke etc. nach Druckmaßstab hinzufügen.
- Zwei Wege zum skalierten Plot: mit Paper Space (Kap. 12) und ohne. Ohne Paper Space: Modell 1:1 zeichnen, Titelblock mit passendem Skalierfaktor einfügen, Datei mit bestimmtem Maßstab plotten.
- Beispiel: Haus 40' × 30' (1:1) plotten bei 1/4" = 1'-0" = 1/48 der Originalgröße. Metrisch: Haus 12 m × 10 m → 1:50.

**Titelblock-Skalierung**
- Titelblock bei 1:1 zeichnen, groß genug für den Grundriss (Beispiel 24 × 36 Sheet). Bei 1/4"=1'-0" Titelblock mit Faktor 48 einfügen, Plot-Maßstab 1/48. Faktor 48 für Overall-Scale (Dimension), Hatch, Linetype, Textgröße verwenden.

**Dimension-Text-Standard**
- ANSI-Standard für Bemaßungstext = **3/16" bzw. 5 mm** (auch AutoCAD-Default). Bei Plot-Maßstab ≠ 1:1 anpassen, damit Text auf Papier weiterhin 3/16" zeigt.
- IMMER die **Fit-Size** (Overall scale, Fit-Tab) ändern, NICHT die Dimension-Text-Size direkt. Auch Pfeilspitzen, Overshoot, Text-Gap etc. werden mitskaliert.

**LTSCALE & HATCH-Scale**
- Bildschirm-Arbeitswert: größter X-Wert geteilt durch 12.
- Für Papier: gleiche Einstellung wie Dimension-Scale/Plot-Scale. Architektonische Hatches (z. B. „arcane", „arroof") sind auf Floor-Plan-Ansicht ausgelegt → Scale 4 für Plot bei 1/4"=1'-0".

**Blöcke zum Compilieren mehrerer Maßstäbe**
- Beispiel 36" × 24"-Sheet mit drei Dateien: Titelblock 36"×24", Fireplace-Detail (16' vertikal), Floor Plan 35'×30'. Floor Plan = Basisdatei (am ehesten geändert).
- Titelblock mit Scale 48 eingefügt (Plot 1/48 → Originalgröße). Fireplace-Detail mit Faktor 4 eingefügt (vierfach), Plot bei 1" = 1'-0".
- Werden Maße auf das vergrößerte Detail gesetzt: Measurement-Scale-Faktor (Primary Units) auf **.25** setzen (Detail 4×). Bei vielen Maßstäben je Größe einen eigenen Dimension Style anlegen.

**View Titles, Section Lines, Break Lines**
- View Titles IMMER UNTER der Ansicht (leicht links/rechts erlaubt, NIE darüber); enthält auch den Maßstab darunter (z. B. „Floor Plan / Scale 1/8" = 1'-0"").
- Bei orthographischer Projektion Titel direkt unter jeder Ansicht.
- Civil/Architektur-Benennung: Top → Plan/Floor Plan; Front → Elevation; Side → Elevation (North/West Elevation bei orientiertem Gebäude, sonst Front Elevation).
- Section Lines zeigen, wo der Schnitt durch das Objekt geht; in Architektur meist auf Floor Plans, oft gezackt durch „schwierige" Stellen; Schnitt dient zur Höhenermittlung der Elevation. Section Lines mit `PLINE` in variierenden Breiten.
- Break Lines an Objektkanten zeigen, dass Material darüber hinaus reicht (z. B. 8' Fundament, nur Teil gezeigt); mechanisch typische Bruchlinie illustriert zylindrisches Objekt. Erstellt mit `PEDIT`/`PLINE`.

**Notationen importieren**
- Standardnotizen (Manufacturing, Building/National Code, Materialien) im Texteditor (Wordpad/Notepad) als `.txt` (ASCII) oder `.rtf` speichern.
- `MTEXT` (Multiline Text) aufrufen → Rechtsklick → „Import Text"-Funktion → `.txt`-Datei einfügen; Größe/Font nachträglich über MTEXT-Menü anpassen.

**Lineweights & Layer Properties Manager**
- Verschiedene Linienstärken je Informationstyp: Objektlinien am dunkelsten, Bemaßungslinien heller, Hatch-Linien am hellsten. Lineweights im **Layer Properties Manager** setzen.
- Plot-Vorbereitung: zu druckende Layer auf Schwarz; Layer **Defpoints** (erscheint automatisch bei Bemaßung) druckt NICHT; Hilfslayer auf unprintable toggeln.
- Objektlinien/Text als Default lassen oder auf **.3** erhöhen; Bemaßungen/Hatches kleiner: Dimensionen **0.13**, Hatch **0.09**.
- Mechanik-Standard: minimum **0.30 mm**, dickere Linien **0.60 mm**. Buchplots: Objekte + Layer 0 mit 0.30 mm; Beispiel-Layer: 0.09 mm (Dimension), 0.13 mm (Hidden/Center).

**Plotting**
- Drei Wege: direkt zum Plotter/Drucker; zu `.plt`-Datei; zu `.pdf` (Internet-Versand).
- `PLOT`-Befehl (älter teils „Print", identisch). Dialog „Plot-Model" (außer in Paper Space). Immer **Preview** vor Druck (Full/Partial Preview).
- Printer/Plotter-Tab leitet Plot zu Geräten oder Datei (`.plt` für anderen Drucker, `.pdf` Portable Document File).
- Neuen Plotter: `CONFIG` bzw. Tools→Options→„Add or Configure a Plotter" → „Add-A-Plotter Wizard"; Treiber sonst aus dem Internet.
- Paper Size erst nach Wahl des Plot-Devices änderbar (Laserdrucker → nur kleines Papier; für größer anderen Plotter). Plot Area Default „Display"; „Window" gibt mehr Kontrolle.
- Plot Scale: plotted inches = drawing inches bzw. plotted mm = drawing units. „Fit" nur wenn echter Maßstab egal. 1/4"=1'-0" → Scale 1/48; 1:50 → .02.
- Plot-Origin = untere linke Papierecke; X/Y-Werte ändern zum Verschieben (z. B. Titelblock platzieren).
- PDF: ab Release 2007/2008 eingebauter PDF-Treiber (AutoCAD e-PLOT im Add-a-Plotter-Wizard → Models → PDF). Release 2006 und älter: „PDF995" aus dem Internet.

### Kapitel 12 — Paper Space (2D-Bemaßungszeichnungen)

**Konzept**
- Bisher Model Space (TILEMODE on). Paper Space = 2D-Document-Layout-Facility; nimmt fertige (bemaßte) Views und platziert sie wie Cut-and-Paste aufs „Papier"; effizientester Weg für Details in verschiedenen Maßstäben.
- Nutzt **Multiple Viewports** (2D und 3D). Model Space = getiltete Umgebung (TILEMODE on, DCS-Icon); Paper Space = non-tiled (TILEMODE off, Paper-Space-Icon, Crosshairs decken den Schirm). View-Titel + Maßstab stehen stets unter der View.

**Zugang Paper Space**
- Layout1-Tab unten anklicken oder `TILEMODE` → `0` (Regenerating drawing). Layout1-Tab rechtsklicken → „Page Setup Manager" → neue Seite anlegen (Defaults nicht überschreiben).
- Erst Plot-Device (Plot-Tab), dann Paper Size (Layout-Tab) setzen — VOR dem Start, sonst viel Nacharbeit. Mit nur Laserdruckern kein Papier größer als **297 × 420 mm (11 × 17)** möglich → über `CONFIG` weiteren Plotter laden.

**Floating Viewports / MVIEW**
- `MVIEW` (Floating Viewports) definiert Views in Paper Space; Größe über Corner-Grips anpassen, weitere Views per MVIEW hinzufügen.
- Viewport-Rahmen liegt im aktuellen Layer → eigenen Layer für Borders anlegen.
- Pull-down bietet: 1 Viewport, 2 Viewports, Restore etc. Verschiedene Viewports können verschiedene aktive Layer haben.

**Model Space ↔ Paper Space**
- Layout1-Tab on = Paper Space (TILEMODE off), Modell weiter zugänglich. Model-Tab on = Model Space (TILEMODE on).
- Toggeln per `MSPACE`/`MS` und `PSPACE`/`PS` oder MODEL/PAPER-Schalter. Zurück zu TILEMODE on stellt Zeichnung wie vor Paper Space wieder her.

**Views skalieren (ZOOM XP)**
- `ZOOM` in Paper Space wirkt auf das ganze Papier (`ZOOM .5X` halbiert Papier + Views). `ZOOM` in Model Space wirkt auf Modell im Viewport (nach XP-Skalierung NICHT erneut zoomen!).
- `PAN`/`MOVE` in Model Space verschiebt Objekte im Viewport; in Paper Space das Papier bzw. die Views zueinander. Alle Modify-Befehle (MOVE, COPY, STRETCH) wirken auf Viewports.
- `ZOOM nXP` setzt Größe relativ zum Papier. Beispiel `MS` → `ZOOM` → `.5XP`.

**Chart 12.1 — ZOOM XP-Faktoren**
| Maßstab | ZOOM-Befehl | Größe relativ zu Real |
|---|---|---|
| 1:1 | ZOOM 1XP | 1/1 |
| 1/2"=1" | ZOOM .5XP | 1/2 |
| 1:50 | ZOOM .02XP | 1/50 |
| 1/4"=1'-0" | ZOOM 1/48XP | 1/48 (= 1/4 × 12) |

**Layer in Viewports / VPLAYER**
- Viewport-abhängige Layer nur in non-tiled-Umgebung (Layout-Tab, TILEMODE off): Layer in manchen Viewports sichtbar, in anderen nicht (verschiedene Maßstäbe, Notationen, Geometrie pro View).
- Beispiel: Details mit 2XP doppelt so groß; irrelevante Layer in Detail-Views einfrieren; neuer Dimension-Layer, Maße in Model Space (echte Modellgröße); Dimension-Layer in den anderen Views einfrieren.
- `VPLAYER` für viele Viewports (nur in Paper Space). Optionen `[?/Freeze/Thaw/Reset/Newfrz/Vpvisdflt]`:
  - `?` listet in gewähltem Viewport eingefrorene Layer.
  - `Freeze` friert Layer in gewählten Viewports.
  - `Thaw` Umkehrung (Layer wieder an).
  - `Newfrz` erzeugt neuen, in allen Viewports eingefrorenen Layer (für Layer, der nur in einem Viewport je sichtbar sein soll).
  - `Reset` setzt Layer auf Default (thawed) zurück.
  - `Vpvisdflt` setzt Default-Sichtbarkeit für beliebigen Layer/Viewport.
  - Ablauf: `F` → Layernamen (z. B. DIM1) → `[All/Select/Current]<Current>:S` → Viewports per Rahmen wählen.

**Bemaßung in Paper Space**
- Endzeichnung: Text + Pfeilspitzen in ALLEN Views gleich groß, egal welcher Viewport-Maßstab; Dimension-Text liest die echte Maßzahl.
- Für verschiedene Maßstäbe je Viewport: `DIMSCALE` = **0** setzen bzw. im Modify-Dimension-Style den Overall scale (Fit-Tab) = 0 → alle Dimensionen in Default-Größe unabhängig vom View-Maßstab.
- Für abweichende Größe: neuen Layer anlegen, Fit-Size als Bruchteil des Zoomfaktors setzen.
- Fit-Tab-Optionen wenn Text/Pfeile nicht zwischen Maßlinien passen: „Either text or arrows (best fit)", „Arrows", „Text", „Both text and arrows", „Always keep text between ext lines", „Suppress arrows if they don't fit".
- Beispieltabelle: Maßstab 1/4"=1'-0" → ZoomXP 1/48XP → Fit 48; Maßstab 1:100 → 1/100XP → Fit 100; Dimensionen anpassbar im Bereich 40–48 bzw. 90–110.
- Regel: View-Maßstäbe müssen Standard sein (1:46 oder 1/4=1'-2" funktioniert NICHT); Flexibilität nur über den Dimension-Scale-Faktor.

**Templates**
- Eigenes Template als „Mytemplate" speichern (mit Layern + Dimension Styles).
- `NEW` listet AutoCAD-Templates (in Paper Space eingerichtete Titelblöcke): **ANSI** (ANSI, American National Standards Institute) = imperial; **ISO** (International Standards Organization) und **JIS** = metrisch. Beispiele: ANSI A–E (Named/Color-Dependent Plot Styles), DIN A0/A1.
