ARP
Address Resolution Protocol
Ein Netzwerkprotokoll, welches die mit einer Netzwerkadresse (IP-Adresse) 
verbundene physische Adresse (MAC-Adresse) ermittelt und danach in den 
ARP-Tabellen der beteiligten Rechner diese Zuordnung einträgt. Das ARP 
wird fast ausschließlich zur Ermittlung von MAC-Adressen im Zusammenhang 
zu vergebenen IPv4-Adressen verwendet, es ist jedoch nicht auf diese 
Funktion beschränkt. Im Bezug auf IPv6-Adressen wird diese Funktionalität 
jedoch nicht von ARP, sondern von einem anderen Protokoll bereitgestellt.
IPv4/IPv6
Internet Protocol Version 4/Internet Protocol Version 6
IPv4 Adressen sind 32 Bit lang, es sind daher maximal 4.294.967.296 
Adressen verfügbar (in der Realität aber nicht alle zur Verteilung an Rechner 
verfügbar, da einige Adressblöcke für spezielle Zwecke reserviert wurden).
IPv6 Adressen sind 128 Bit lang, davon bilden die ersten 64 Bit das 
sogenannte Präfix und die letzten 64 Bit bilden (bis auf seltene Ausnahmen) 
einen für die Netzwerkschnittstelle eindeutigen Interface-Identifier.
SMTP
Simple Mail Transfer Protocol (Einfaches-E-Mail-Transportprotokoll)
Bei SMTP handelt es sich um ein Protokoll der Internetprotokollfamilie, 
welches für den Austausch von E-Mails in Computernetzen verwendet wird. 
Vorrangig wird dieses Protokoll dabei zum Einspeisen und zum Weiterleiten 
von E-Mails benutzt. Das Abholen von Nachrichten wird jedoch nicht von 
SMTP, sondern von anderen, spezialisierten Protokollen erledigt.
API
Application Programming Interface (wörtlich übersetzt Anwendungs-
programmierschnittstelle, meistens aber Programmierschnittstelle oder 
Anwendungsschnittstelle genannt)
Eine API ist ein Programmteil, welcher von einem Softwaresystem 
anderen Programmen zur Verfügung gestellt wird, damit diese an das 
System angebunden werden können. Diese Schnittstelle definiert die 
Programmanbindung nur auf Quelltext-Ebene und benötigt, damit sie 
bereitgestellt werden kann, eine detaillierte Dokumentation der  
Schnittstellen-Funktionen mitsamt ihren Parametern entweder auf Papier  
oder als elektronisches Dokument.
PPPoE
Point-to-Point over Ethernet (Punkt-zu-Punkt über Ethernet)
Unter PPPoE versteht man die Verwendung des Netzwerkprotokolls PPP 
(Point-to-Point Protocol) über eine Ethernet-Verbindung. Dieses Protokoll 
besteht aus zwei Phasen: der PPPoE Discovery und der PPP Session. In 
der PPPoE Discovery Phase wird die MAC-Adresse von einem Access 
Concentrator ermittelt, welcher den logischen Endpunkt von PPP-Sitzungen 
bildet und für Aufgaben wie die Zuweisung von Sitzungsparameter wie  
IP-Adressen zuständig ist. In der zweiten Phase, der sogenannten PPP-
Session, werden dann Daten nach PPP ausgetauscht.
CBR/VBR
Constant Bit Rate: Egal was sich im Bild ändert, die Bitrate bleibt immer gleich
Variable Bit Rate: Die Bitrate kann sich anpassen und damit Speicherplatz 
sparen. (Qualitätsverlust möglich)
WAN
Wide Area Network (Weitverkehrsnetz)
Das WAN ist ein Rechnernetz, welches sich im Gegensatz zu einem 
LAN oder MAN über einen sehr großen geografischen Bereich erstreckt 
(über mehrere Länder oder möglicherweise sogar mehrere Kontinente). 
WANs werden eingesetzt, um verschiedene LANs (aber auch einzelne 
Rechner) miteinander zu vernetzen. Es gibt einige WANs, die bestimmten 
Organisationen angehören und nur von diesen verwendet werden, aber 
andere WANs werden von Internetanbietern errichtet bzw. erweitert, um 
einen Zugang an das Internet zu gewähren.
UPnP
Universal Plug and Play
UPnP dient zur herstellerübergreifenden Ansteuerung von Geräten (wie 
z.B. Audio-Geräten, Routern und Druckern) über ein auf IP basierendes 
Netzwerk, unabhängig davon, ob das Netzwerk über eine zentrale 
Kontrolle durch ein Residential Gateway (die technische Schnittstelle 
zwischen einer Wohnumgebung und der Außenwelt) verfügt, oder nicht.

P2P
Peer-to-Peer/Rechner-Rechner-Verbindung (peer = Gleichgestellter) sind 
synonyme Bezeichnungen und stehen für die Kommunikation unter Gleichen, 
in diesem Kontext ist dies auf ein Rechnernetz bezogen. Bei einem reinen 
Peer-to-Peer-Netz sind alle Computer gleichberechtigt und können Dienste 
sowohl in Anspruch nehmen als auch zur Verfügung stellen.
FTP
File Transfer Protocol (Dateiübertragungsprotokoll)
Das FTP ist ein Netzwerkprotokoll, welches dazu dient, Daten über IP-
Netzwerke zu übertragen. Genauer gesagt wird es benutzt, um Dateien 
von einem Client zu einem Server (Hochladen), von einem Server zu 
einem Client (Herunterladen) oder clientgesteuert zwischen zwei FTP-
Servern (File Exchange Protocol) zu übertragen. Zusätzlich dazu kann FTP 
verwendet werden, um Verzeichnisse anzulegen und auszulesen, sowie um 
Verzeichnisse und Dateien umzubenennen oder zu löschen.
SNMP
Simple Network Management Protocol (Einfaches Netzwerk-
verwaltungsprotokoll)
Das SNMP ist ein Netzwerkprotokoll, das entwickelt wurde, damit 
Netzwerkelemente (wie z.B. Router, Server, Switches, usw.) von einer 
zentralen Station aus überwacht und gesteuert werden können. Die 
Kommunikation zwischen den Geräten, welche überwacht werden, und  
der Überwachungsstation werden dabei durch das Protokoll geregelt.
 
CVBS
Composite Video
CVBS ist ein analoges Verfahren, welches zur Übertragung eines Bildkanals 
verwendet wird, dies ist vergleichbar mit einem einzelnen Fernsehkanal. 
Allerdings geschieht diese Übertragung ohne Audio bzw. Ton.
Bei Composite Video wird die gesamte Bildinformation über eine einzige 
Leitung übertragen, wodurch jedoch die Bildqualität vergleichsweise 
schlecht ist. Bei CVBS kann das verwendete Bildformat PAL, SECAM 
oder NTSC sein, es ist also stets ein analoges Fernsehsignal in normaler 
Auflösung, also niemals ein HDTV-Signal.
PAL/NTSC
PAL = Phase-Alternating-Line
NTSC = National Television Systems Committee
PAL und NTSC sind zwei Verfahren zur Farbübertragung beim analogen 
Fernsehen.
NTSC wurde in weiten Teilen Amerikas und in einigen Länder Ostasiens 
eingesetzt, während PAL vor allem in Europa, aber auch in Australien und 
in vielen Länder in Afrika, Asien und Südamerika benutzt wurde. Beide 
Verfahren wurden jedoch gegen Ende der 2000er Jahre größtenteils durch 
digitales Fernsehen ersetzt.
Das PAL-Verfahren wurde mit dem Ziel entwickelt, die bei NTSC 
auftretenden, störenden Farbton-Fehler automatisch zu kompensieren, da 
dies bei NTSC nur manuell möglich war und die Fehler nur unbefriedigend 
ausgeglichen werden konnten.
NTP
Network Time Protocol
Das NTP ist ein Standard, welcher dazu dient, intelligenten Endgeräten 
über das Internet die aktuelle Uhrzeit mitzuteilen. Zum Beispiel wird die 
Synchronisierung von Echtzeituhren in Computersystemen über NTP mithilfe 
von paketbasierten Kommunikationsnetzen umgesetzt. Zusätzlich zu NTP  
gibt es auch noch das SNTP (Simple Network Time Protocol), bei welchem 
es sich um eine vereinfachte Version von NTP handelt.
ISP
Internet Service Provider (Internetdienstanbieter, oft auch nur Provider 
genannt)
Bei einem ISP handelt es sich um einen Anbieter von Diensten, Inhalten 
oder technischen Leistungen, welche für die Nutzung oder den Betrieb von 
Inhalten und Diensten im Internet erforderlich sind. Einige Leistungen von 
ISPs sind z.B. die Bereitstellung von Internetzugang und Domain-Hosting, 
Server-Hosting, usw.
